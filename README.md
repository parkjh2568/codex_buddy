# 옹기봇

바탕화면의 작은 버디와 Codex로 대화하는 앱입니다.
이미지·파일을 함께 보내고, 작업 중 떠오른 질문은 대기열에 넣을 수 있습니다.

개발 중인 앱이며 현재 확인한 환경은 macOS Apple Silicon입니다. Windows 실행은 아직 검증하지 않았습니다.

## 빠르게 실행

Node.js 24를 권장합니다. 프로젝트 폴더에서 실행하세요.

```sh
npm ci
npm run demo
```

체험 모드는 모델을 호출하지 않습니다.
실제 대화에는 설치·로그인된 Codex CLI가 필요합니다.

```sh
npm start
```

실제 대화는 연결한 계정의 이용량을 사용합니다.

## 기본 사용법

- 버디를 클릭하거나 `⌘ + Shift + Space`로 대화창을 엽니다.
- 글을 입력하고 `Enter`로 보냅니다. 줄바꿈은 `Shift + Enter`입니다.
- 말투 옆 `+`에서 이미지·파일·작업 목적을 선택합니다.
- 작업 중 보낸 질문은 대기열 순서대로 이어집니다.
- 심플 말풍선은 답변 후 30초에 숨겨집니다. 입력·처리 중에는 미루며 버디를 눌러 다시 엽니다.
- 설정에서 캐릭터·말투·이름을 바꿉니다. 앱 종료는 메뉴 막대의 `종료`입니다.
