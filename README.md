# 옹기봇 · Alpha 0.1 (alpha.9)

바탕화면에서 꼬물꼬물 움직이는 작은 친구에게 질문하고, 로컬 Codex CLI의 답변을 말풍선으로 받는 Electron 앱입니다. 캐릭터는 실행 코드가 없는 팩으로 교체합니다. 현재 실행 검증 환경은 macOS Apple Silicon이며 Windows를 고려한 창·아이콘 처리를 포함합니다. Windows 네이티브 실행·배포는 아직 검증하지 않았습니다.

## 실행

이 PC용 Apple Silicon 빌드: `dist/OnggiBot-darwin-arm64/OnggiBot.app`을 더블클릭합니다.

- 캐릭터 또는 작은 말풍선을 클릭하면 대화창이 열립니다.
- 바탕화면 캐릭터는 팩 원본 크기의 50%로 표시합니다. 기본 캐릭터는 75×95px입니다. 대기 안내는 3초 후 사라지며 캐릭터에 마우스를 올리면 잠깐 다시 표시합니다. 작업 중·승인 대기 안내는 해당 상태 동안 유지합니다.
- 캐릭터 본체를 누른 채 드래그하면 원하는 위치로 옮깁니다. 이동 중에는 안내와 흔들림을 숨기고 마지막 위치를 저장합니다. 기본 대기 창은 120×143px이며 투명 여백은 뒤쪽 앱의 클릭을 통과시킵니다. 안내가 보일 때만 창을 잠깐 넓힙니다.
- Dock/작업 표시줄 영역이나 화면 밖으로 이동할 수 있습니다. 안내가 열려도 캐릭터 위치는 유지합니다. 보이지 않으면 트레이/메뉴 막대의 `버디 위치 초기화`로 되돌립니다. 재실행·화면 구성 변경 시 보이지 않는 위치는 자동 복구합니다. [플로팅 동작·검증 범위](docs/FLOATING_PET_UPDATE.md)
- macOS의 `⌘ + Shift + Space`로 대화창을 엽니다. Windows 대응 키는 `Ctrl + Shift + Space`이며 Windows 실기 검증은 후속 작업입니다. 단축키 충돌 시 트레이/메뉴 막대 아이콘을 사용합니다.
- `Enter`로 보내고 `Shift + Enter`로 줄을 바꿉니다. 한글 조합 중 Enter는 전송하지 않습니다.
- 긴 대화는 최근 최대 100개/약 256KiB 텍스트부터 표시하고, 위쪽의 `이전 내용 더 보기`로 앞선 메시지를 추가합니다. 저장 기록은 삭제하지 않습니다.
- `이전 대화`에서 옹기봇 대화만 검색·선택하고 같은 대화를 이어갑니다. 항목 오른쪽 `삭제`→확인 창의 `영구 삭제`로 로컬 기록과 연결된 실제 CLI 세션을 삭제합니다. CLI 파생 세션도 삭제되며 기존 복구 백업은 유지합니다. [삭제 범위·실패/재시도](docs/DELETE_CONVERSATIONS.md)를 참고합니다. 새 대화를 만들어도 지난 기록은 보존합니다.
- 입력 박스 밖의 하단 줄에서 모델·추론 단계·Standard/Fast 속도를 선택합니다. 반복 안내와 별도 하단 연결 문구는 숨기고 모델 조회/오류 안내만 필요할 때 표시합니다. 상단 연결 표시에 마우스를 올리면 모드 설명을 확인합니다. 변경은 다음 질문부터 적용하며 대화는 이어집니다.
- 앱 기본 모델은 `gpt-5.6-luna`, 추론 단계는 `high`입니다. 직접 선택한 설정은 이후 실행에도 유지됩니다.
- 답변은 Markdown 제목·목록·표·인용·코드·링크로 표시합니다. 전체 `복사`는 원문, `코드 복사`는 해당 코드 블록입니다.
- 상단은 `대화`·`이전 대화`이며 우측 톱니바퀴로 설정을 엽니다. `수신 대답속도 측정`을 켜면 새 질문의 입력→앱 수신→CLI 전송→응답 완료→화면 반영 시간과 첫 응답·큐 대기·전체를 `mm:ss.ffff`로 표시합니다. [측정 기준과 제한](docs/RESPONSE_TIMING.md)을 참고합니다.
- 설정에서 캐릭터, 움직임 줄이기, 항상 위에 표시, 작업 폴더, Codex 실행 파일을 선택합니다.
- 처음에는 실제 Codex 모드입니다. `체험 모드`를 켜면 모델 호출 없이 UI를 체험합니다.
- 대화창의 `×`와 `Esc`는 창을 숨깁니다. 프로그램 종료는 메뉴 막대의 `종료`입니다.

macOS 직접 설치용 로컬 알파 빌드이며 서명·공증하지 않았습니다. 다른 PC에 배포할 서명된 설치 프로그램은 후속 작업입니다.

개발 환경은 Node.js 22.12.0 이상과 npm이 필요합니다. 검증한 환경은 Node.js 24.21.0입니다. OS별 준비·실행·패키징·결과물·Windows 검증 한계는 [macOS·Windows 빌드 가이드](docs/BUILD_GUIDE.md)를 참고합니다.

```sh
npm ci
npm start
```

모델 호출 없는 체험 실행:

```sh
npm run demo
```

## Codex 준비

Codex CLI 설치와 로그인이 필요합니다. 앱이 CLI 위치를 자동으로 찾으며, 못 찾으면 설정에서 실행 파일을 선택합니다.

현재 앱에는 최초 설치 안내·로그인 상태 진단·브라우저 로그인 버튼이 없습니다. 처음 사용하는 PC의 연결 공백과 개선 계획은 [최초 연결 편의성 검토](docs/FIRST_RUN_REVIEW.md)를 참고합니다. 해당 문서는 분석 결과이며 아직 구현된 기능은 아닙니다.

```sh
codex --version
codex login
codex login status
```

이 PC에서 검증한 버전은 `codex-cli 0.160.0`입니다. GUI로 실행된 앱의 PATH는 터미널과 다를 수 있어 절대 실행 파일 경로도 지원합니다. 초기 작업 폴더는 앱 데이터 아래의 빈 `workspace`입니다. 프로젝트 질문을 하려면 설정에서 해당 폴더를 선택합니다. 작업 폴더·CLI 연결을 변경하면 현재 대화를 목록에 보존하고 새 대화를 준비합니다. 이전 대화를 열면 해당 대화의 작업 폴더·CLI 연결도 복원합니다.

연결은 `codex app-server --listen stdio://`의 JSONL 프로토콜을 사용합니다. 사용자 질문은 원문으로 JSON 입력에 전달하며 셸 명령 문자열에 끼워 넣지 않습니다. 계정과 모델 제공자는 로컬 CLI 설정을 사용합니다. 모델·추론 단계는 앱에서 질문별로 지정할 수 있습니다. 앱이 로컬에서 실행돼도 OpenAI 모델 사용에는 네트워크와 계정 이용량이 필요합니다.

`CLI 기본값`과 `기본 추론`을 함께 선택하면 CLI의 유효 설정으로 돌아갑니다. 모델을 직접 선택한 뒤 `기본 추론`을 선택하면 해당 모델의 카탈로그 기본 단계를 사용합니다. `↻`는 모델 목록과 CLI 기본 설정을 다시 조회하며 모델을 호출하지 않습니다. 목록과 모델별 추론·Fast 옵션은 CLI 응답을 사용합니다. 대화창을 열거나 포커스·모델 선택 영역에 접근하거나 질문을 보낼 때 5분 캐시가 만료되면 자동 재조회합니다. CLI 실행 파일이 변경되면 유휴 상태에서 새 프로세스에 연결해 다시 조회합니다. 작업 중에는 CLI 교체를 다음 유휴 사용까지 미룹니다. 표시된 목록이 계정의 모든 모델 실행 권한을 보장하지는 않습니다. 실행 실패 시 다른 모델로 자동 변경하지 않습니다.

Fast는 CLI가 해당 모델에 제공할 때만 선택할 수 있고 사용량이 증가합니다. 속도의 앱 기본값은 Standard이며 CLI 전역 설정은 수정하지 않습니다. 모델 변경으로 기존 속도가 미지원이 되면 Standard로 돌아갑니다.

각 질문은 전송 시 모델·추론 단계·속도를 기록합니다. 실행 중 설정을 바꿔도 이미 대기 중인 질문의 모델은 바뀌지 않습니다. 앱 자체 설정만 저장하며 사용자의 Codex 전역 설정 파일은 수정하지 않습니다. 자세한 확인 결과는 [Markdown과 모델 설정](docs/MARKDOWN_MODELS.md)에 있습니다.

알파는 `read-only`에서 시작합니다. 읽기 범위를 선택한 작업 폴더로 제한한다는 보장은 없습니다. 범위는 Codex CLI 권한 설정을 따릅니다. 명령·파일 변경 승인 요청은 대화창에서 허용·거절·취소할 수 있습니다. 별도 권한 프로필 요청은 알파에서 추가 권한을 부여하지 않습니다. 지원하지 않는 도구 요청은 거절하거나 오류로 응답합니다.

참고: [App Server](https://learn.chatgpt.com/docs/app-server), [Codex 인증](https://learn.chatgpt.com/docs/auth).

## 캐릭터 팩

기본 팩은 클리피의 종이클립 형태를 참고해 직접 작성한 SVG `옹기 클립`, 교체 검증용 `새싹 옹기`입니다. 제공된 참고 이미지 파일을 앱에 복사하지 않았습니다.

`톱니바퀴 설정 → 캐릭터 팩 가져오기`에서 `manifest.json`이 있는 폴더를 선택합니다. 실행 중에도 교체할 수 있으며 대화·Codex 연결은 이어집니다. 자세한 규격과 예시는 [캐릭터 팩 규격](docs/CHARACTER_PACKS.md)에 있습니다.

## 기록과 요청 처리

- 설정·대화 목록을 `state.json`, 대화별 메시지를 `conversations/<id>.json`에 저장합니다. 기존 120개 메시지 제한은 제거했으며 파일 하나의 크기는 32MiB까지입니다.
- 목록은 이 설치의 옹기봇이 기록한 대화만 포함합니다. 다른 Codex 앱·CLI 대화는 가져오지 않습니다. 기존 알파에 남아 있는 현재 대화는 원본 백업 후 자동 이관합니다.
- 제목·최근 내용으로 검색하고 목록에서 열어 같은 Codex 대화를 이어갑니다. CLI 기록 조회가 실패해도 로컬 기록을 표시합니다. 자세한 동작과 복구 범위는 [이전 대화](docs/CONVERSATIONS.md)에 있습니다.
- Codex 대화 ID를 저장해 앱 재시작 후 이어갑니다. CLI 자체 기록은 CLI가 관리합니다.
- 한 번에 한 질문을 처리합니다. 실행 중에도 최대 10개 질문을 대기시킬 수 있습니다.
- 대기 질문은 개별 취소할 수 있고, 실행 중 질문은 `중단`으로 취소합니다.
- 종료·절전·연결 중단 후 불확실한 요청은 중단 상태로 남기고 자동 재실행하지 않습니다.
- 대화·목록 파일 교체 중 종료되면 저장 저널을 검사해 복구합니다. 확인값이 맞지 않으면 원본을 보존하고 복구 필요 안내를 표시합니다. 완료 답변 저장 실패 시 다음 대기 질문을 실행하지 않습니다. 자세한 저장 방식은 [로컬 안정화 보고서](docs/LOCAL_STABILITY.md)에 있습니다.
- 상태 파일 자체가 손상되면 백업한 뒤 새 기록으로 시작합니다.
- 설정의 `내 기록 · 캐릭터 폴더 열기`로 실제 저장 위치를 확인합니다. macOS 기본 위치는 `~/Library/Application Support/OnggiBot/`입니다.
- 화면을 숨겨도 진행 중인 작업의 수신은 메인 프로세스가 계속 담당합니다. 숨겨진 캐릭터 애니메이션은 정지합니다.

기록은 평문입니다. 인증 토큰은 앱 기록에 저장하거나 캐릭터 팩에 넣지 않습니다. Codex 로그인을 재사용합니다.

## 검증과 빌드

```sh
npm run check       # 구문, 기본 캐릭터 팩 규격
npm test            # JSONL, 오류 복구, 팩 경계, 저장 복구
npm run smoke       # 네이티브 UI, 체험 대화, 교체, FIFO, 취소
npm run smoke:pointer # 수동 마우스 검증: 투명 여백 뒤 주황 버튼 클릭 후 자동 종료
npm run smoke:floating # 플로팅 창·화면 경계·말풍선 앵커 검증
npm run smoke:performance # 1000개 기록·변경분 IPC·추가 로드·용량 경계 검증
npm run smoke:timing # 모델 호출 없이 구간·FIFO 대기·화면 반영·토글 검증
npm run smoke:delete # 테스트 CLI로 삭제·취소·실패·재시도·보존 검증
npm run codex:delete-smoke # 실제 검증용 세션 생성/응답/삭제 (계정 이용량 사용)
npm run smoke:history # 모델 호출 없는 대화 목록·검색·재개·격리·재시작 검증
npm run smoke:models # 모델 호출 없는 테스트 CLI: 모델 변경·추론·대기 질문 고정
npm run codex:smoke # 실제 모델 호출: 응답, 프로세스 재연결, 대화 재개
npm run smoke:real  # 실제 모델 호출: 네이티브 UI에서 질문/응답
npm run package     # 현재 운영체제/CPU용 앱 생성
```

실제 모델 검증은 계정 이용량을 사용합니다. `smoke`는 실제 모델을 호출하지 않습니다. 검증 화면과 결과는 `artifacts/`에 저장하며 배포 앱에는 포함하지 않습니다.

캐릭터 SVG 재생성: `npm run characters:generate`. 앱/메뉴 막대 PNG와 Windows ICO 재생성: `npm run icons:generate`. macOS 메뉴 막대 아이콘은 사용자가 제공한 `assets/tray-source.png`를 원본으로 18px와 Retina용 36px를 생성하고 템플릿 이미지로 표시합니다. Windows 트레이는 기존 컬러 앱 아이콘을 사용합니다. macOS `.icns` 재생성은 [개발 구조 문서](docs/ARCHITECTURE.md)를 참고합니다.

## 알파 범위와 다음 단계

Slack 연동, 의미 기반 감지, 공용 서버·브로커, 음성, 자동 화면 배회, 파일 첨부, ZIP 팩 설치, 앱 설치 파일 자동 업데이트는 아직 구현하지 않았습니다. Markdown의 raw HTML과 이미지 자동 로딩, 코드 구문 강조, 수식·체크박스 확장은 미지원입니다. 현재 캐릭터 애니메이션은 상태별 SVG 자세와 본체의 공통 움직임 조합입니다. 임의 스크립트·3D 모델·스프라이트 프레임 타임라인은 지원하지 않습니다.

작업 범위·완료 기준·후속 작업은 [TASKS.md](TASKS.md), 검증 근거와 제한은 [알파 검증 보고서](docs/ALPHA_REPORT.md)에 기록합니다.
