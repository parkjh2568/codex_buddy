## 삭제하지 않은 내용과 근거

- **소스와 검사:** 작성한 JavaScript 66개에서 정적 require/import 324개를 분석했고 누락된 상대 import는 없었다. 모듈 export와 검사 스크립트는 다른 코드·package 명령·문서 진입점에서 참조된다. 참조 존재만으로 실행 성공을 보장하지 않으므로 동적 smoke 분기·워커·HTML·IPC·CSS·manifest 연결도 함께 대조했다.
- **호환·복구:** 저장 v1→v2 이관, 구형 CLI의 미지원 메서드 처리와 원격 기록의 불명확한 텍스트 매칭 거절은 기존 기록 보존에 필요하다. `legacy`라는 이름만으로 제거하지 않았다. 관련 fixture와 실패/재시작 검사를 유지한다.
- **UI·주석:** `motion-float`/`motion-bounce`는 manifest 값으로 동적으로 조합한다. aria 연결 ID·모서리 조절 ID·숨김/복구 상태도 유지한다. 불변 IPC 객체와 macOS 긴 문자열 글꼴 비용을 설명하는 주석은 현재 구현 이유이며 완료 TODO가 아니다. 추가로 제거할 근거가 있는 오래된 작업 주석은 확인하지 못했다.
- **의존성·자산:** Markdown/정제 라이브러리 3개와 빌드/검사 도구 5개는 사용 중이다. 4개 기본 캐릭터 팩·3개 스킨·원본 트레이 그림·생성 아이콘·라이선스 고지는 실행/생성/배포에 필요하다.
- **산출물:** `artifacts/`에는 재현 원자료·실패 로그·복구 앱·백업이 함께 있다. 기존 앱/복구 압축본·사용자 데이터·이전 검증의 해시를 일괄 삭제하지 않았다. 이번 작업은 디스크 용량이나 런타임 성능 개선을 측정한 작업이 아니다.
- **남은 요구:** 실제 IME·배터리/절전·OS 배너/클릭·Spaces·새 계정·다른 OS/제공자·외부 배포를 완료 처리하지 않았다. 외부 에셋/오디오·기억/음성·중앙 FIFO의 착수 조건과 Slack 대기를 유지한다.

## 검증과 복구

`npm run lint`와 `npm run check`를 실행해 통과했다. ESLint의 미정의/미사용 변수 검사, CSS 구문·값·중복 검사, JavaScript 구문 검사와 기본 팩 4개 검증을 포함한다. Markdown 80개에서 로컬 링크 713개와 제목 앵커 17개를 확인했고 깨진 대상은 없었다. 이동/복사한 문서 10개와 기존 이력·근거 문서 39개는 링크를 같은 대상으로 정규화한 뒤 본문 보존을 대조했다. 실행 입력 141개와 기존 앱 ASAR 3개는 전후 해시가 일치한다.

이번 변경은 문서에 한정한다. 실행 입력이 동일하므로 단위 190개·Electron 15종·네이티브 입력/클립보드·패키지 검사를 다시 실행하거나 앱을 재생성하지 않았다. 해당 수치는 [이전 Mac 구현 검증](MAC_FOLLOWUP_RESULT_2026-10-15.md)의 결과다. 문서 이동에 따라 그 보고서의 상대 링크도 바뀌었으므로 당시 해시는 당시 복구 사본과 대조한다. 기존 원자료·최종 감사 JSON을 새 검증 결과로 덮어쓰지 않았다.

정리 전 프로젝트 소유 파일 197개와 기존 앱 ASAR 3개의 해시를 [기준 장부](../artifacts/legacy-cleanup-2026-10-16/baseline-manifest.json)에 보존했다. 해당 폴더의 `baseline/`에서 필요한 파일을 대조·복구할 수 있다. 최신 파일을 일괄 덮어쓰지 말고 [이동 목록](../artifacts/legacy-cleanup-2026-10-16/relocations.json)에 따라 문서 위치와 링크를 함께 복원한다. 최종 검증·변경 목록은 [검증 장부](../artifacts/legacy-cleanup-2026-10-16/verification.json), 참조 분석은 [코드 참조 장부](../artifacts/legacy-cleanup-2026-10-16/code-reference-audit.json)에 기록한다.
