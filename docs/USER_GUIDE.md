# 옹기봇 사용법

버디를 클릭해 질문하고 자료를 첨부하며 같은 대화를 이어갑니다. 실행 방법은 [README](../README.md), 지원 환경과 실제 확인 범위는 [검증 상태](ALPHA_REPORT.md)를 참고하세요.

## 첫 연결

실제 대화에는 설치된 Codex CLI와 해당 제공자의 로그인이 필요합니다. CLI는 앱에 포함하지 않습니다. 체험 모드는 모델을 호출하지 않으며, 개발용 체험 실행도 일반 앱과 같은 기록 폴더를 사용합니다.

앱이 CLI·인증·작업 폴더·모델 목록을 확인합니다. 연결에 문제가 생기면 표시되는 버튼으로 해결하세요.

| 화면의 상태 | 할 일 |
|---|---|
| 연결이 끊김 | `다시 연결`. 앱도 유휴 상태에서 한 번 자동 복구를 시도합니다 |
| CLI를 찾지 못함 | `자동으로 다시 찾기`. 필요하면 `설치 안내`를 열거나 실행 파일을 직접 선택합니다 |
| 작업 폴더가 없음 | `작업 폴더 선택`으로 접근할 폴더를 지정합니다 |
| 로그인이 필요함 | `ChatGPT로 로그인` 후 기본 브라우저에서 진행합니다 |
| 로그인 대기 중 | 완료를 기다리거나 취소합니다. 대기는 5분 후 만료됩니다 |
| 모델 목록 조회 실패 | 표시된 원인을 해결한 뒤 다시 확인합니다 |

기존 CLI 로그인을 재사용하며 앱의 로그인 취소가 CLI 계정을 로그아웃하지는 않습니다. 설정의 진단 정보 내보내기는 대화·인증 정보·개인 경로를 제외합니다.

처음 작업 폴더는 앱 데이터 아래의 빈 폴더입니다. 프로젝트 자료를 질문하려면 설정에서 해당 폴더를 선택하세요. CLI나 작업 폴더를 바꾸면 이전 대화를 남기고 새 대화를 준비합니다. 이전 대화를 열면 그 대화의 연결 문맥을 복원합니다. 연결이 돌아와도 중단된 질문이나 대기 질문을 자동으로 다시 보내지는 않습니다.

## 글과 자료 보내기

`Enter`로 보내고 `Shift + Enter`로 줄을 바꿉니다. 한글 조합 중 Enter는 전송하지 않습니다. 입력창은 여러 줄에 맞춰 늘어나며, 지난 답변을 읽는 중에는 `맨 아래로`로 최신 답변에 돌아옵니다.

말투 옆 `+`에서 이미지·파일 첨부와 이미지 붙여넣기를 선택합니다. 파일 드롭도 지원합니다. 첨부는 최대 8개, 파일당 16MiB·합계 32MiB입니다. 선택한 사본을 보내므로 이후 원본을 바꿔도 이미 접수한 자료는 유지됩니다. 보내기 전 `×`로 첨부를 제거할 수 있습니다. 첨부만 보내면 자료 확인 요청을 함께 전송합니다.

PNG/JPEG/WebP 이미지를 지원합니다. PDF·Office 등 일반 파일의 실제 읽기 가능 여부는 연결한 CLI 도구와 환경에 따라 달라집니다. 체험 모드에서는 첨부를 모델에 보내지 않습니다.

같은 `+` 메뉴의 접힌 `작업 목적 · 스킬`에서 대화·요약·분석·계획·리뷰 목적과 지원 스킬을 선택합니다. 선택 내용은 입력창에 요약되며 이미 접수한 질문에는 나중 변경을 적용하지 않습니다.

## 작업 중 다음 질문 보내기

일반·심플 모드 모두 한 번에 한 질문을 실행합니다. 작업 중 보낸 질문은 최대 10개까지 대기하며 앞 작업의 종료 저장 후 순서대로 실행됩니다. 접수 당시의 자료·모델·말투·목적을 유지합니다.

대기줄에서 질문을 보류·편집·취소하거나 전체 대기를 멈추고 `계속`으로 재개합니다. 편집 확정과 접수에 실패하면 초안을 유지합니다. 실행 중인 질문은 `중단`으로 멈춥니다. 연결 중단·절전·종료 뒤 불확실한 질문은 중단 상태로 남으며 자동 재실행하지 않습니다. 승인과 추가 질문 요청은 대화창에서 직접 응답합니다.

## 심플 말풍선과 상세 대화

설정의 `대화와 화면`에서 `심플 말풍선 열기`를 선택합니다. 처음에는 입력창만, 답변이 오면 선택한 답변의 글·이미지와 하단 입력창을 표시합니다. 긴 답변은 말풍선 안에서 스크롤하며 `↗`로 같은 대화와 초안을 넓게 펼칩니다.

답변의 저장·이미지 처리·화면 표시가 끝나고 30초가 지나면 입력창을 포함한 말풍선 전체를 숨깁니다. 초안·한글 조합·첨부 선택·팝업·승인·작업/대기·편집·저장/복구·중요 오류가 있으면 미루고 보호가 끝나면 다시 30초를 줍니다. `×`는 즉시 숨기며 초안이나 작업을 취소하지 않습니다. 버디를 클릭하면 다시 엽니다.

상세 창은 네 모서리를 드래그해 조절합니다. 모서리에 키보드 포커스를 두면 방향키로, Shift와 함께 누르면 더 크게 조절합니다. 상세 크기와 위치는 같은 실행 동안 유지하며 앱 재시작까지 저장하지 않습니다. `×`와 Esc는 창을 숨기고, 앱 종료는 메뉴 막대의 `종료`입니다.

버디는 드래그로 옮깁니다. 화면 밖으로 가서 보이지 않으면 메뉴 막대의 `버디 위치 초기화`를 사용하세요. 화면이 제대로 돌아오지 않으면 `화면 복구`를 사용합니다. 버디 하단 메뉴는 마우스를 올리면 잠시 나타납니다.

## 모델과 답변 표시

입력창의 모델 버튼에서 모델·추론 단계·Standard/Fast 속도를 고릅니다. 선택 가능한 항목은 연결한 CLI와 계정에 따라 다릅니다. Fast가 제공되면 선택할 수 있으며 사용량이 증가합니다. 설정 변경은 다음 질문부터 적용하고 실행·대기 중인 질문은 바꾸지 않습니다.

CLI 설정을 따르려면 모델을 `CLI 기본값`, 추론을 `기본 추론`으로 고릅니다. `↻`는 목록과 기본 설정을 다시 읽습니다. 목록이 보인다고 실제 실행 권한까지 보장하지는 않으며 실행 실패 시 다른 모델로 자동 변경하지 않습니다.

답변의 제목·목록·표·인용·코드·링크를 표시합니다. 전체 `복사`는 답변 원문을, `코드 복사`는 해당 코드만 복사합니다. 임의 HTML·외부 이미지 자동 로딩·코드 구문 강조·수식·실제 체크박스는 지원하지 않습니다. `수신 대답속도 측정`은 기본 꺼짐이며 켠 뒤 보낸 질문부터 표시합니다. [측정 구간과 의미](RESPONSE_TIMING.md)를 참고하세요.

생성 이미지에는 미리보기와 원본 열기·복사·저장을 제공합니다. 예전 대화의 이미지가 빠졌다면 `결과 다시 확인`으로 해당 CLI 기록을 다시 읽습니다. 이 작업이 새 이미지를 생성하지는 않습니다. 생성·사용량·저장 오류는 카드의 안내를 확인하세요.

## 친구 모습과 말투 바꾸기

설정에서 친구 이름, 캐릭터, 스킨, 대화 글자 배율과 항상 위에 표시를 선택합니다. 이름은 1–20자로 저장하며 기존 질문·답변 원문은 바꾸지 않습니다. 대화 글자 배율은 본문과 질문 입력에 적용합니다.

기본 스킨 `따뜻한 종이`는 종이색 바탕과 차분한 갈색 강조를 사용합니다. `대화 · 이전 대화 · 설정`으로 이동하며, 현대 스킨은 상세 창을 넓히면 탐색이 왼쪽으로 옮겨집니다. `친구`에서 캐릭터와 크기를, `움직임`에서 정숙/일상/생동감 표시 프로필을 고릅니다.

`화면 스킨`의 `클래식 도우미`는 노란 말풍선·회색 창·입체 버튼을 사용합니다. 캐릭터와 말투는 그대로 유지하며 같은 메뉴에서 다른 스킨으로 돌아갈 수 있습니다. 실제 화면 수용 상태는 [검증 상태](ALPHA_REPORT.md)를 확인하세요.

말투는 친절·상냥한 장문·핵심 단답·퉁퉁이 중에서 고릅니다. 설정의 Markdown 편집이나 `MD 폴더`에서 캐릭터별 기본 성격과 말투를 수정합니다. 저장된 말투를 복제해 이름 변경·보관·복원할 수 있습니다. 기본 내용 복원은 선택한 원본을 백업합니다. 편집 초안은 저장 전까지 메모리에만 있으므로 앱 종료 전에 저장하세요.

외부에서 MD가 바뀌면 파일과 앱 초안을 비교합니다. `초안 유지`·`최신 파일로 초안 교체`·`비교한 파일에 초안 저장` 중 선택하며, 비교 뒤 파일이 또 바뀌면 다시 확인합니다. 저장·복원 중 새로 입력한 초안은 유지합니다.

캐릭터 팩은 폴더를 골라 미리본 뒤 설치합니다. 업데이트는 편집 MD를 유지하고 제거한 팩은 보관합니다. 팩 교체·제거는 작업과 대기열을 비운 뒤 진행합니다. 내보내기는 작업 중에도 가능하며 편집 말투 포함은 기본 꺼짐입니다. [팩 만들기와 규격](CHARACTER_PACKS.md)을 참고하세요.

정숙은 장식 움직임과 자동 승인창 열기를 줄이고 일상은 대기 안내를 숨깁니다. 생동감은 지원 팩의 눈 깜빡임을 켭니다. 움직임 줄이기·배터리 움직임 절약을 선택할 수 있습니다. 잠금 중에는 표시를 억제하고 절전은 현재 작업을 중단합니다. 복귀 뒤 대기 질문은 `계속`으로 재개합니다.

## 기록 찾기와 보관

`이전 대화`에서 이 설치의 옹기봇 대화를 검색하고 이어갑니다. 제목·최근 내용 검색은 아직 펼치지 않은 항목에도 적용하며 `본문 검색`은 확인한 기록 수와 제한·읽기 실패를 안내합니다. 작업·대기 질문을 마친 뒤 대화를 전환하세요. 새 대화는 이전 기록을 지우지 않습니다.

항목의 `···`에서 제목 변경·Markdown 내보내기·삭제를 선택합니다. 삭제는 로컬 기록과 연결된 실제 CLI 세션·파생 세션에 영향을 줍니다. [삭제 범위와 실패 시 재시도](DELETE_CONVERSATIONS.md)를 확인하세요. 다른 Codex 앱·CLI의 모든 대화를 가져오는 기능은 없습니다. [조회·검색 범위](CONVERSATIONS.md)를 참고하세요.

설정의 `내 기록 · 캐릭터 폴더 열기`로 실제 저장 위치를 확인합니다. 기록과 첨부 사본은 평문으로 보관합니다. 질문·선택 자료는 연결한 CLI에 전달하며 실제 모델 응답은 해당 계정과 네트워크를 사용합니다. CLI 인증 토큰을 앱 기록이나 캐릭터 팩에 복제하지 않습니다.

설정의 `보관 파일과 복구`에서 참조·보관량을 확인하고 선택한 미참조 캐시를 복구 보관하거나 복원합니다. 복구 보관은 영구 삭제가 아니므로 전체 디스크 사용량을 줄이지 않습니다. 기존 파일을 덮어쓰지 않으며 자동 만료는 없습니다.

## 문제가 생겼을 때

| 문제 | 확인할 내용 |
|---|---|
| 답변이 오지 않음 | 연결 상태·모델 오류·승인/추가 질문 요청·보류된 대기줄 확인 |
| 이미지가 보이지 않음 | 카드 오류 확인 후 `결과 다시 확인`. 원본 생성 실패와 앱 저장 실패를 구분 |
| 파일을 읽지 못함 | 지원 이미지 형식·첨부 한도·CLI의 파일 읽기 도구 확인 |
| 기록 저장/복구 오류 | 원본·저널을 보존하고 저장 위치와 디스크 오류 확인. 다음 질문이 멈춘 상태에서 [복구 규칙](LOCAL_STABILITY.md) 참고 |
| 버디가 화면 밖에 있음 | 메뉴 막대의 `버디 위치 초기화` |
| 단축키가 작동하지 않음 | 메뉴 막대에서 열고 단축키 충돌 확인 |

알파는 읽기 전용 설정으로 시작하지만 읽는 범위가 선택한 작업 폴더 안으로만 제한된다는 보장은 없습니다. 범위는 CLI 권한을 따릅니다. 명령·파일 변경 요청은 확인 후 허용·거절·취소하며, 지원하지 않는 요청과 별도 추가 권한 프로필은 허용하지 않습니다.
