# 연결 복구·생성 이미지 적용 기록

구현·검증일 2026-10-08, 정리 2026-10-10. 대상 alpha.13/build28, macOS arm64.

## 확인한 원인과 결과

사용자가 지정한 ‘할부 거인’ 대화의 소유 CLI 기록을 읽어 확인했다. 1024×1536 PNG, 3,371,159바이트의 완료된 `imageGeneration` 결과가 있었지만 기존 앱은 텍스트 항목만 저장했다. Markdown 이미지 로딩도 비활성 상태였다. 생성 실패가 아니라 앱 수신·보관·표시 누락이었다.

native 생성 이미지와 성공한 MCP 이미지 결과를 별도 카드로 수신·검증·보관하도록 수정했다. 지정한 기존 그림을 격리 채팅과 패키지의 실제 decode/Store 재로드에서 확인했다. 새 이미지 생성이나 해당 사용자 대화의 모델 재호출은 하지 않았다.

## 구현 순서와 구조

1. 설치 CLI 0.162.0-alpha.2의 생성 스키마·소유 thread를 확인했다.
2. 연결/인증 상태와 로그인 시도 수명을 분리하고 복구 UI를 붙였다.
3. 응답 이미지의 검증·원본/미리보기 저장 경계를 추가했다.
4. 턴 수신·종료 저장·기존 기록 병합·renderer 표시를 연결했다.
5. 오류 회귀, 격리 UI, 패키지 일치와 원본 보존을 검사한 뒤 일반 앱을 적용했다.

`connection-setup.cjs`는 프로세스 탐색·인증/로그인 수명, `response-images.cjs`는 이미지 검증·디스크 보관을 담당한다. 검증/실패 경계가 다른 부분만 모듈로 분리했다. 큐·턴 처리·설정 변경·UI 상태는 기존 함수 안에 인라인으로 유지했다. 캐릭터 팩에는 실행 코드를 추가하지 않았다.

## 사용 방법

| 상황 | 버튼·동작 |
|---|---|
| 연결 중단 | 유휴 상태에서 한 번 자동 복구, 실패 시 `다시 연결` |
| 미로그인 | `ChatGPT로 로그인` 후 기본 브라우저에서 완료 |
| 로그인 중단 | `로그인 취소`, 또는 5분 만료 후 다시 시도 |
| CLI 경로 변경/미설치 | `자동으로 다시 찾기`, 필요하면 `설치 안내` 후 재탐색 |
| 없어진 작업 폴더 | `작업 폴더 선택` |
| 기존 답변의 이미지 누락 | 해당 대화를 열고 `결과 다시 확인` |
| 큰 이미지 확인 | 이미지 카드의 `원본 열기` |

중단된 질문은 자동 재전송하지 않는다. 대기 질문은 연결 중단 뒤 일시 정지하고 사용자가 `계속`으로 재개한다. 같은 CLI 재연결은 현재 대화를 유지하고 다른 CLI/폴더 선택은 이전 기록을 보존하며 새 대화를 준비한다.

## 예외·안전 경계

인증은 `account/read`로 기존 캐시를 먼저 확인한다. 인증·프로세스·모델 목록 준비를 구분한다. 공식 HTTPS 인증 호스트·시도 ID를 검사하고 중복 로그인·일찍 도착한 완료 알림·취소·연결 교체·5분 만료를 처리한다. 앱에 이메일·토큰·인증 링크를 저장하거나 공용 CLI 계정을 로그아웃하지 않는다. 체험 전환은 진행 중인 자체 로그인 시도를 취소한다.

PNG/JPEG/WebP, 원본 16MiB 이하, 한 변 4096px 이하·16MP 이하, 답변당 최대 8개를 지원한다. 헤더 검사 후 Node/네트워크 없는 sandbox 창에서 실제 decode한다. 512px PNG 미리보기와 수정하지 않은 원본을 해시 파일로 보관하고 대화 JSON에는 참조만 저장한다. 캐릭터 팩의 기존 검증 기본값은 유지했다.

파일 경로는 해당 작업 폴더 또는 현재 thread의 CLI 생성 폴더를 확인하며 저장/조회에서 링크·해시·소유 참조를 검사한다. 활성 소유 대화의 이미지에 한해서 미리보기·원본 열기를 허용한다. 원격 Markdown 이미지 자동 로딩은 허용하지 않는다. 보관 폴더의 모든 파일을 포함해 512MiB 상한을 적용하며 원본을 임의로 지우지 않는다.

이미지 단독 답변도 보존한다. 생성 취소·한도 초과·잘못된 이미지·decode 시간 초과·폴더/디스크 오류는 이미지 카드 실패 안내로 처리한다. 텍스트 대화는 유지한다. 종료 저장은 이미 도착한 이미지의 검증 완료를 기다리고 남은 pending은 중단/실패로 기록한다. 초기 턴 이벤트의 제어 256KiB/128개 한도와 이미지 32MiB 한도를 구분했다.

UI 검사에서 브라우저/원본 외부 열기는 테스트 대역으로 확인했다. 실제 신규 계정의 브라우저 로그인 콜백, OS 이미지 연결 프로그램 클릭, Windows 실기·실제 잠금/절전은 검증하지 않았다. macOS 실제 앱 UI 도구는 `timeoutReached`로 실패해 사용자 프로필의 버튼 클릭·이미지 기록 갱신을 완료했다고 표현하지 않는다. 사용자는 새 앱에서 해당 대화의 `결과 다시 확인`을 누를 수 있다. 사용자 프로필 파일을 도구로 직접 편집하지 않았다.

격리 Electron 실행은 제한된 실행 환경에서 SIGABRT가 발생했고 GUI 실행 권한을 사용한 12종 검사가 통과했다. 패키징의 제한 환경 DNS 실패 이후 공식 Electron 접근으로 성공했다. ICNS는 패키지와 일치하며 `.icon` 미제공 경고는 남는다. 서명/공증·설치 프로그램·자동 업데이트는 이번 범위 밖이다.

공식 프로토콜 근거: [App Server](https://learn.chatgpt.com/docs/app-server), [인증](https://learn.chatgpt.com/docs/auth). 이미지 항목의 구체적인 필드는 설치 버전의 생성 스키마와 실제 소유 결과를 기준으로 검증했다. 실제 응답과 테스트 CLI/체험 응답의 검증 범위를 구분한다.


2026-10-10의 첨부/선입선출 확장과 현재 build29 전달 결과는 [후속 적용 기록](ATTACHMENTS_AND_QUEUE_2026-10-10.md)을 따른다. 위 build28 적용 경로·검사 수는 당시 결과다.
