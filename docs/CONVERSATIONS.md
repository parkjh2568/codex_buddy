# 대화 조회와 검색

이 설치의 옹기봇이 기록한 소유 대화만 목록에 표시한다. 다른 Codex 앱/CLI의 모든 세션을 가져오지 않는다. 사용자 조작은 [사용법](USER_GUIDE.md#기록-찾기와-보관), 파일과 저널은 [저장 계약](LOCAL_STABILITY.md)이 기준이다.

## 목록과 연결 문맥

전체 목록을 정렬·필터링한 뒤 100개씩 표시한다. 제목·최근 미리보기 검색은 아직 펼치지 않은 항목도 포함한다. 수동 제목·즐겨찾기를 보존하며 첫 질문을 기본 제목으로 사용한다. 작업/대기 질문이 있으면 전환을 막고 대화별 초안은 실행 중에만 기억한다.

모델 설정은 앱 전체에 적용하므로 과거 대화를 열어도 현재 선택 모델을 유지한다. 작업 폴더·CLI 경로·체험 모드는 해당 대화 값으로 복원한다. 소유 등록부의 thread ID만 조회하며 이후 질문은 같은 세션을 재개한다. 조회 자체는 모델을 호출하지 않는다. CLI 조회가 실패해도 로컬 기록을 표시하고 안내한다.

새 CLI 세션의 threadSource는 onggi_bot이다. 로컬 사용자 ID와 turn/item ID를 기록해 병합을 대조한다. 다른 앱에서 같은 등록 세션을 이어간 텍스트도 조회할 수 있지만 도구 실행 로그·추론 내용은 말풍선 기록에 가져오지 않는다. 체험 대화는 로컬 기록만 사용한다.

## 원격 페이지와 화면 표시

대화 열기는 metadata의 ID를 확인하고 최신 DESC/full 25턴 한 페이지만 요청한다. 먼저 보관한 로컬 메시지의 표시 범위를 늘리고 이후 사용자의 이전 내용 요청에 원격 25턴씩 읽는다. 최초 명시적 미지원(-32601)만 legacy 전체 조회로 돌아간다.

안정된 turn/item ID·순서·cursor 진전·수명·용량을 검증해 기존 메시지·첨부·목적과 병합한다. 대체/중복/삽입을 구분하고 모호한 레거시 연결은 원본을 유지하며 거절한다. 저장 성공 뒤 cursor/seen을 갱신한다. 취소·연결/폴더/화면 세대 변경은 늦은 결과를 폐기하고 저장 시작 뒤에는 취소를 제한한다. 취소가 진행 중 RPC를 물리 중단하는 것은 아니다.

로컬 화면은 최근 최대 100개/약 256KiB 텍스트부터 표시하고 이전 묶음을 추가한다. 가장 최근 메시지는 크더라도 하나를 표시한다. 변경 upsert와 ID 순서만 전달하고 대화/renderer 변경은 캐시를 초기화한다. 더 펼치면 DOM이 늘어나는 단계 표시이며 전체 가상화는 아니다. 저장 파일의 메시지를 화면 개수로 잘라 지우지 않는다.

불러온 원문은 파일 한도 안에서 보존하지만 화면은 메시지당 100,000자까지 표시하고 생략을 알린다. 새 CLI 스트림의 답변 수집도 항목 합계 100,000자까지이며 초과는 CLI 원문 확인을 안내한다. 표시 한도와 새 응답 수집 한도는 서로 다르다.

## 본문 검색

명시적 검색은 최대 100개 대화·32MiB 논리 payload·결과 50건이다. query별 worker 하나가 파일 읽기·parse·검색을 수행한다. main은 저장 대기 전부터 revision과 대화를 고정하고 취소·검색어/대화 변경·재로드·잠금/절전과 worker 종료 대기 뒤에도 소유권을 확인한다.

최초 확인한 파일 크기를 예약하고 실패 파일도 보수적으로 예산에 청구한다. 성장/EOF 검출용 최대 1바이트/파일은 논리 payload와 별도다. 한 파일이 읽는 중 커져도 그 파일 때문에 다음 전체 예산을 읽지 않는다. 읽기 실패 수·확인 수·제한을 표시하고 정상 결과는 유지한다. 부분 실패를 정상적인 0건으로 표시하지 않으며 기존 파일/저널을 쓰지 않는다.

## 이관과 삭제

기존 v1에서 남은 현재 대화는 백업 후 등록한다. 옛 120개 제한으로 지운 메시지·새 대화로 이미 잃은 로컬 정보·미등록 외부 세션은 로컬만으로 자동 복원하지 못한다. 현재 등록 세션은 CLI 조회로 보완할 수 있다. 개수/용량 무제한 검색과 PC 간 동기화는 제공하지 않는다.

삭제의 로컬/원격·파생 범위와 재시도는 [삭제 계약](DELETE_CONVERSATIONS.md)을 따른다. 테스트 명령은 [빌드 가이드](BUILD_GUIDE.md#4-검증-명령과-현재-windows-한계), 현재 검증은 [알파 보고서](ALPHA_REPORT.md)를 따른다.
