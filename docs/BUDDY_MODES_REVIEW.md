# 버디·스킨·미니 대화·페르소나

현재 앱은 세 데이터형 스킨(paper/night/mono), 일반/미니 대화, 캐릭터별 Markdown 기본 성격/말투, v1 정적 팩과 v2 눈 깜빡임 팩을 지원한다. 구현 전 비교·계획과 build26 수용 기록은 [설계 이력](history/BUDDY_MODES_REVIEW.md)에 보존했다.

## 현재 계약

스킨은 UI 색상, 캐릭터 팩은 외형/상태/프레임, MD는 질문의 기본 성격과 말투를 담당한다. 설정의 이름과 배율은 외형에 독립적이다. 미니 대화는 최근 질문/답변 한 쌍을 보여주고 확장하면 같은 대화·초안을 유지한다. 일반/미니에서 작업 중 보낸 질문은 같은 FIFO를 사용한다.

MD는 캐릭터별로 분리하고 선택을 저장한다. 편집/복제/이름 변경/보관/복원은 사용자 MD와 registry의 소유권을 검사한다. 기본 내용 복원은 원본을 백업한 뒤 진행한다. 질문 접수 시 instructions/hash·모드·모델을 고정하므로 뒤의 편집이나 외형 변경은 이미 접수된 질문을 바꾸지 않는다.

팩은 미리보기에서 decode·규격을 검사한 뒤 확정한다. 교체/제거/내보내기는 작업 종료 후 진행하고, 편집 MD는 유지하며 제거 팩은 보관한다. 내보내기는 manifest/참조 이미지/MD만 포함하고 편집 MD 포함은 기본 꺼짐이다. 규격·보안·한도는 [캐릭터 팩](CHARACTER_PACKS.md), 소유권/복구는 [구조](ARCHITECTURE.md)를 따른다.

## 표시·수명

정숙/일상/생동감은 안내와 장식 정책이며 실제 진행 상태/저장 오류/승인 필요를 숨기지 않는다. 화면 잠금은 표시·프레임·렌더 ACK를 억제한다. 절전은 현재 작업을 중단하고, 복귀 후 큐는 사용자가 계속한다. 기본 50%와 35/65% 배율을 유지한다.

캐릭터 목록에는 metadata/썸네일만 보내고 활성 팩의 자산/프레임만 전송한다. 프레임 timer는 창 좌표나 저장과 분리하고 숨김/교체/실패 때 정리한다. 실제 decode 실패는 fallback을 사용하며 metadata 검사만으로 성공을 주장하지 않는다.

Windows/DPI·물리 잠금/절전·장시간 번들/배터리 평가는 [후속 작업](../TASKS.md)이다. 실제 모델의 말투/미니 검증은 [알파 결과](ALPHA_REPORT.md)의 날짜별 근거를 따른다. Live2D/VRM·배회·다중 캐릭터·음성·기억과 Slack/중앙 FIFO는 미착수 범위다.
