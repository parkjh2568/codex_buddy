# 플로팅 버디 동작

캐릭터 창은 안내 표시와 관계없이 기본 120×143 논리 픽셀을 유지하고, 안내는 별도 196×52 투명 창으로 표시한다. 대화창은 460×최대 740, 미니는 360×410이다. 화면 작업 영역이 작으면 대화창 크기를 줄인다. 캐릭터 배율/팩에 따른 크기 변경은 [팩 규격](CHARACTER_PACKS.md)을 따른다.

## 이동·클릭·복구

드래그는 시작 지점의 절대 좌표·포인터 캡처를 사용한다. 캐릭터는 Dock/작업 표시줄·화면 밖으로 이동할 수 있고 안내 표시/숨김은 캐릭터 앵커를 바꾸지 않는다. 안내는 화면 경계 안에 배치하고 위 여유가 없으면 아래에 표시한다. 여백과 숨긴 하단 메뉴는 클릭을 통과시킨다.

대기 안내는 3초 뒤 숨고 캐릭터 hover 동안 유지한다. 하단 메뉴는 hover 진입 후 3초 뒤 숨는다. 드래그 중 안내/메뉴/장식 동작을 숨긴다. 재시작·화면 구성 변경에서는 보이지 않는 위치만 복구하며 트레이의 `버디 위치 초기화`와 `화면 복구`를 제공한다. renderer 복구에서는 notice 클릭 영역을 다시 등록하고 모델 질문을 재전송하지 않는다.

macOS는 비활성 panel·플랫폼 전용 창 옵션을 사용한다. Windows는 공통 이동/포커스·컬러 트레이·ICO/폰트 경로를 유지하지만 실제 동등 동작은 아직 확인하지 않았다.

## 검증 명령과 한계

`npm run smoke:floating`은 합성 이동·앵커·클릭 영역, `npm run smoke:pointer`는 포인터 경로를 검사한다. `--verify-floating-restore`, `--verify-floating-recovery`는 첫 실행과 같은 격리 프로필을 순서대로 사용한다. `--native-floating-review`는 실제 마우스 드래그·클릭을 필요로 한다.

build13–24의 좌표/프레임/네이티브 검증 수치와 실패/재시도 조건은 [플로팅 이력](history/FLOATING_PET_UPDATE.md)과 [UI 이력](history/UI_UX_REFINEMENT.md)에 있다. 자동 검사는 Windows Snap/100–150%·혼합 DPI·IME·실제 절전/파일 잠금, macOS OS 타일링 미리보기 소멸·모니터 분리·전체 화면 Spaces 실기를 대신하지 않는다. [후속 작업](../TASKS.md)을 유지한다.
