# 옹기봇 구조·코드 검토

현재 구현은 개인 로컬 Codex CLI를 재사용하는 Electron 앱이다. 한 질문만 실행하며 접수·종료 저장·후속 질문의 순서를 보장한다. 미니와 일반 대화는 같은 대화를 사용하고, 실제 응답과 체험 응답을 구분한다. [현재 구조](ARCHITECTURE.md)와 [미완료 작업](../TASKS.md)을 기준으로 변경한다.

## 유지하는 결정

단순 상태/문자열/화면 로직은 함수 안에 둔다. CLI 프로세스, 저장 워커, 인증 시도, 이미지 decode, 첨부 사본, 팩/MD 복구는 소유권과 실패 경계가 달라 별도 모듈을 유지한다. 캐릭터 팩과 스킨은 실행 코드 없는 데이터다.

Electron·renderer 번들·Markdown 정제는 실제 창/프로토콜/저장 요구를 처리한다. 현재 사용 중인 의존성을 추측으로 제거하거나 작은 함수를 범용 도구로 재분리하지 않는다. 런타임 교체·DB·브로커·플러그인 프레임워크는 현재 정리 범위에 추가하지 않는다.

## 현재 확인할 경계

- 저장 실패/중간 종료: 원본·저널 보존, 쓰기 차단, 중단 상태 확정과 안전한 재시도.
- 늦은/다른 턴 알림: 소유 thread/turn 검증, 중단 대상 보존, 질문 자동 재전송 금지.
- 팩·MD: snapshot/revision·원본 편집 보존·단계 복구·미리보기 후 확정.
- 첨부/응답 이미지: 소유 ID·경로·링크·해시·파일/픽셀/저장 용량 검사, 텍스트 기록 유지.
- UI: 숨김/미니 DOM 절약, 새 대화 초안 이전, notice 클릭 영역의 renderer 복구.

## 근거와 남은 범위

최신 사용 가능 기능과 검증 범위는 [알파 결과](ALPHA_REPORT.md), 이번 삭제/보존 판단과 검증은 [정리 결과](CLEANUP_RESULT_2026-10-10.md)를 따른다. Windows·물리 절전/다중 모니터·실제 브라우저 로그인·배터리·서명/공증은 해당 환경에서 확인하기 전 완료로 표시하지 않는다.
