계획의 `미구현`·`제안`·`확인 필요`는 작성 당시의 판단이다. 후속 구현 여부는 현재 TASKS와 기능 문서에서 확인한다. 실기·플랫폼·조건부 기능을 완료로 바꾸기 위해 이동한 것은 아니다.

이력의 `현재`, 검사 수, 소스 행 번호와 고정 staging 경로는 작성 당시 기준이다. 같은 경로가 이후 빌드에서 재사용될 수 있으므로 원래 결과 JSON의 실행 시각·source hash와 함께 대조한다. 현재 후보의 수정·측정·실기 한계는 [Mac 후속 결과](../MAC_FOLLOWUP_RESULT_2026-10-15.md), 현재 문서 정리는 [2026-10-16 정리 결과](../LEGACY_CLEANUP_RESULT_2026-10-16.md)를 따른다.
