# Alpha 0.1 검증 범위

최신 개발 소스와 staging 후보는 alpha22/build38이다. [Mac 후속 결과](../MAC_FOLLOWUP_RESULT_2026-10-15.md)에 state/복구 저널 제한 읽기·첨부 비동기 수명·원격 최신 25턴부터 단계 조회를 기록한다. 단위 190개·lint/check·격리 Electron 15종·패키지 85개 파일·strict ad-hoc 서명과 실제 패키지 격리 실행을 통과했다. 실제 macOS 선택기 다중 첨부·취소와 네 모서리 조절, 사용자 승인 후 OS 클립보드 API 검사도 확인했다. CPU/I/O·대용량 저장·이미지 비용은 전후 원자료와 한계를 함께 기록한다. 실제 모델 질문은 추가하지 않았으며 기존 일반 앱과 build37 복구본은 보존한다.

직전 개발 소스 alpha21은 다음 범위를 확인했다. [2026-10-14 후속 구현 결과](REMAINING_IMPLEMENTATION_RESULT_2026-10-14.md)에 제한된 `readHistory` FD 읽기와 변경 감지, 말투 옆 `+`, 대화/설정 정렬, 답변 중심 심플 화면·보호 해제 후 30초 전체 숨김, 상세 4모서리 조절·실행 중 bounds 보존을 기록한다. 당시 단위 177개를 통과했다. macOS 격리 네이티브 실행에서 실제 4모서리 조작으로 460×740→450×730→440×720→430×710→420×700을 확인했다. 전체 Electron 15종·패키지 85개 파일·strict ad-hoc 서명·실제 패키지 격리 실행을 통과했다. 심플 30초 실제 대기·390/460/720 크기×3스킨·최종 ASAR 네이티브 4모서리도 확인했다. 실제 모델 호출·새 계정 인증·다른 OS 검증은 이번 결과에 포함하지 않는다.

직전 후보는 alpha20/staging build36이다. [2026-10-13 최종 후속 결과](FINAL_IMPLEMENTATION_RESULT_2026-10-13.md)의 단위 147개·격리 Electron 14종·패키지 85개 파일, 이미지/첨부·선택형 보관 복원과 strict ad-hoc 서명을 확인했다. 당시 실제 네이티브 격리 실행에서 보관량 AX 조회·알림 show·정상 종료를 확인했다. 기존 앱 사본은 이번 후속 구현의 복구 자료로 보존한다.

이후 [레거시 정리](LEGACY_CLEANUP_RESULT_2026-10-13.md)에서 개발 소스/번들을 갱신하고 단위 147개·격리 Electron 14종·CSS 전후 36조건을 확인했다. 해당 정리에서는 새 앱 패키지를 만들지 않았으며 build36의 소스/ASAR 일치는 생성 당시 결과다. `+`/30초 숨김/모서리 드래그는 이후 alpha21에서 구현했다.

이후 [성능 수정](PERFORMANCE_OPTIMIZATION_RESULT_2026-10-13.md)의 소스는 당시 단위 156개·격리 Electron 14종·lint/check를 통과했다. 2026-10-14 구현 전 대조에서는 실행 입력 63개 해시가 그 소스와 일치했지만 staging build36의 main·attachments·renderer 번들·CSS는 달랐다. [남은 작업](REMAINING_WORK_REPORT_2026-10-14.md)은 이 시점의 기록 읽기 상한·새 UI·실기/최초 연결·전달 조건을 분석한 기준이며, UI 구현은 상단 alpha21 결과에, 이후 수정과 현재 검증 후보는 alpha22 Mac 후속 결과에 기록한다.

2026-10-13의 전체 소스 감사와 당시 135개 단위 검사는 [최종 전체 검토](FULL_CODE_REVIEW_2026-10-13.md)를 따른다. 아래 126개·84개 파일·소스/ASAR 일치는 build34 생성 당시의 결과다. build34는 후속 실행 결과의 apps-before에, 초기 alpha19/build35는 apps-initial에 검증 사본으로 보존했다.

일반 실행 경로의 macOS arm64 앱은 alpha.14이며 이번 Info.plist 확인값은 CFBundleVersion 30이다. 기존 전달 기록의 build29 표기와 구분한다. 이미지/파일 첨부·불변 사본·일반/미니 FIFO까지 적용돼 있다. 이번 정리 작업은 [실행 결과](CLEANUP_RESULT_2026-10-10.md)에서 소스와 staging의 검증 및 설치 여부를 따로 기록한다.

build34 생성 당시 소스 alpha.18와 별도 staging build34는 [후속 작업 결과](BUDDY_FOLLOWUP_RESULT_2026-10-10.md)를 따른다. 단위 126개·격리 Electron 14종·패키지 84개 파일과 현재 소스 해시를 대조했다. 인증/연결 교체 경합·순차 이미지 내보내기·25턴 기록 페이지 병합·기존 회귀를 확인했고 macOS 묶음의 strict ad-hoc 서명을 검증했다. 실제 OS 클립보드 복사/읽기·버튼 첨부·복원도 확인했다. 잠금 해제 후 알림 show 이벤트는 확인했으나 화면 도구 시간 초과로 실제 배너/클릭은 미검증이다. 이번 작업의 실제 모델 질문은 0회이며 일반 실행 앱은 교체하지 않았다. alpha.17/build33은 별도 실행 폴더에 유지하고 alpha.16/build32·alpha.15/build31은 [정리 복구 압축본](../../artifacts/legacy-cleanup-2026-10-12/cleanup-targets.tar.gz)에 보관한다.

alpha.17의 단위 117개·격리 Electron 14종과 편집/첨부 경합·fallback 설정·사용량 병합·이미지 읽기 수정은 [당시 품질 개선 결과](QUALITY_CYCLE_RESULT_2026-10-10.md)에 유지한다.

alpha.15/build31의 실제 CLI 기능 조회·모델 2회·알림 show 및 당시 검증은 [버디 확장 기록](BUDDY_EXPANSION_RESULT_2026-10-10.md)에 유지한다. OS 배너·클릭과 다른 모델/제공자·플랫폼은 이번 수정의 검증 범위에 포함하지 않는다.

## 기준 릴리스의 확인 결과

2026-10-10 build29은 단위 90개·격리 UI 13종·실제 Luna/high의 이미지 색상/파일 표식 읽기·패키지 소스/worker/아이콘 일치 검증을 수행했다. 사용 프로필/CLI/실제 호출 여부와 제한은 [첨부·대기열 적용 기록](../ATTACHMENTS_AND_QUEUE_2026-10-10.md)을 따른다. 현재 정리 작업에서 이를 재실행했다고 표현하지 않는다.

연결 복구·브라우저 URL/시도 ID·이미지 결과 복원은 [alpha.13 적용 기록](../CONNECTION_AND_IMAGES_2026-10-08.md), 이전 결함 수정/실제 소유 턴 중단/측정은 [2026-10-08 수정 결과](ISSUE_REMEDIATION_RESULT_2026-10-08.md), 더 이전 alpha/build별 숫자와 전달 결과는 [이전 알파 보고서](ALPHA_REPORT.md)에 있다.

## 유지하는 제한

- Windows/Intel·혼합 DPI·Snap·IME·실제 파일 잠금/설치와 macOS 물리 다중 모니터/절전/Spaces는 별도 실기 검증이 필요하다.
- 실제 미로그인 계정의 브라우저 인증 콜백은 미검증이다. 모의 로그인 결과를 실제 인증 성공으로 표시하지 않는다.
- 로컬 read-only는 선택 폴더만 읽는다는 보장이 아니다. 범위는 CLI 권한 설정을 따른다. 추가 권한 프로필은 부여하지 않는다.
- 라이브 부분 응답은 비정상 종료로 손실될 수 있다. JSON 저널 복구는 DB 트랜잭션/전원 장애 내구성 보장이 아니다.
- 원격 기록은 최신 full 25턴부터 가져오고 이전 내용을 명시적으로 확장한다. 로컬 JSON 전체 읽기·페이지별 전체 저장 비용은 남으며, 전부 확장할 때 누적 I/O가 증가한다. 다른 CLI/제공자 수용은 후속이다. CPU 표본은 통제된 배터리·전체 시스템 측정이나 성능 향상 보장이 아니다.
- staging은 로컬 ad-hoc 서명을 적용한다. Developer ID/공증·설치 프로그램·자동 업데이트는 제공하지 않는다. Slack·중앙 FIFO·음성/기억은 미착수다.

구현과 남은 범위는 [TASKS](../../TASKS.md), 재현 명령/패키징은 [BUILD_GUIDE](../BUILD_GUIDE.md)를 따른다.

2026-10-12의 검사 출력/프로필·완료 문서 이동·과거 산출물 정리와 추가 검증은 [파일 정리 결과](LEGACY_FILE_CLEANUP_RESULT_2026-10-12.md)를 따른다. 제품 소스 22개와 기존 ASAR의 실행 파일 84개는 정리 전후 해시를 대조한다.
