# 옹기봇 작업 계획

현재 목표는 macOS Apple Silicon에서 작고 조용한 버디와 빠르고 안정적으로 대화하는 경험이다. 캐릭터·이름·말투를 유지하면서 필요할 때 도움을 받는 흐름을 우선한다. 로컬 일반/미니 대화의 FIFO는 구현돼 있다. 다중 클라이언트 중앙 FIFO는 별도 후속 과제이며 Slack S01–S17은 사용자 요청에 따라 대기한다.

현재 구조는 [ARCHITECTURE](../ARCHITECTURE.md), 검증과 전달 범위는 [ALPHA_REPORT](../ALPHA_REPORT.md)를 따른다. 완료한 A/C/D/E/P/G/W 작업의 날짜별 검사 수·환경·실패 근거는 [기존 작업 이력](TASKS_BEFORE_CLEANUP_2026-10-10.md)과 [검토 이력](README.md)에 보존했다.

[2026-10-14 남은 작업과 완료 기준](REMAINING_WORK_REPORT_2026-10-14.md)은 이전 분석 기준이다. alpha21의 UI·읽기 보강은 [당시 결과](REMAINING_IMPLEMENTATION_RESULT_2026-10-14.md)에 유지한다. 최신 [Mac 후속 결과](../MAC_FOLLOWUP_RESULT_2026-10-15.md)는 alpha22/build38의 state/저널 읽기·첨부 수명·원격 단계 조회와 자동 검증을 기록한다. 단위 190개·Electron 15종·패키지 85개 파일·strict 로컬 서명·격리 패키지 실행을 통과했다. 직전 build37 전체 앱과 기준 소스 194개는 해당 결과의 복구 자료로 보존한다.

## 2026-10-13 코드 정리·최적화

입력 ID·공유 이미지 저장·계정 사용량 조회·팩 export·모달 Escape·질문 label과 검사 실패 수명을 보완했다. 삭제/말투 fixture 하나를 통합하고 decode 픽셀 예산 초과에서 후속 처리를 중단한다. 단위 134개와 격리 Electron 14종, 마지막 보완 후 영향 경로 재검증을 통과했다. 실제 모델 호출과 새 배포 패키지 생성은 없다. 소스 변경과 기존 설치본·플랫폼 수용 범위는 [최적화 결과](OPTIMIZATION_RESULT_2026-10-13.md)를 따른다. 이후 남은 문서 대조와 추가 저장/검사 경계를 확인했다. 최종 135개 단위 검사와 전체 범위·후속 계획은 [최종 감사](FULL_CODE_REVIEW_2026-10-13.md)를 따른다. 기존 build34는 추가 변경 전의 배포본이다.
