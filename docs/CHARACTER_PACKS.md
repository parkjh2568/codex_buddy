# 캐릭터 팩 v1/v2

캐릭터 팩은 이미지·JSON과 선택적인 페르소나 Markdown 데이터만 포함합니다. 본체의 대화, 권한, Codex 연결을 수정하지 않습니다.

## 최소 구성

```text
my-character/
  manifest.json
  idle.svg
```

```json
{
  "schemaVersion": 1,
  "id": "my-character",
  "name": "내 친구",
  "description": "작고 포근한 친구",
  "version": "1.0.0",
  "size": { "width": 150, "height": 190 },
  "bubbleAnchor": { "x": 0.65, "y": 0.12 },
  "motion": "sway",
  "states": { "idle": "idle.svg" }
}
```

`id`는 영문 소문자로 시작하는 소문자·숫자·하이픈, 최대 48자입니다. 같은 ID는 미리보기에서 업데이트 확인 후 교체하며 기본 팩은 보호합니다. 이름은 1~60자입니다. 크기는 논리 픽셀로 가로/세로 각각 60~220입니다. 앵커는 캐릭터 좌상단 기준 0~1이며 말풍선 위치와 꼬리를 보정합니다.

`motion`: `sway`(좌우 흔들림), `float`(위아래 움직임), `bounce`(작은 도약). 기본값은 `sway`입니다. 생각 중·알림·답변·쉬기 상태는 공통 상태 애니메이션이 우선합니다. 움직임 줄이기 설정은 모든 캐릭터에 적용합니다.

## 상태

| 키 | 의미 |
|---|---|
| idle | 대기 |
| listening | 질문 입력 |
| thinking | 실행 중 |
| replying | 응답 도착 직후 |
| attention | 승인·추가 답변 필요 |
| error | 작업 실패 |
| sleeping | 사용자가 쉬기 선택 |

`idle`은 필수입니다. 나머지 파일이 지정되지 않으면 `idle`로 대체합니다. 지정된 파일이 실제로 없으면 팩 설치를 거절합니다.

## 이미지와 설치

- SVG, PNG, WebP를 지원합니다. 이미지 하나는 최대 3MB, 팩의 참조 이미지 합계는 최대 24MB입니다.
- 경로는 팩 내부 상대 경로입니다. 외부 경로와 외부를 가리키는 심볼릭 링크를 거절합니다.
- SVG의 style 요소·style 속성·스크립트·이벤트·SMIL·외부 참조·DOCTYPE·ENTITY·`url(...)`은 거절합니다. 정적 inline CSS도 지원하지 않으며 단순 presentation attribute(예: fill/stroke)나 PNG/WebP로 내보냅니다. sandbox DOM 검사도 namespace/localName으로 실행 요소·style·참조를 거절합니다. 그라디언트/필터 참조 제한은 v1/v2에 같습니다.
- JS, CSS, HTML, 모델 코드, 셸 스크립트는 팩 실행 자산으로 사용하지 않습니다.
- 설치 시 manifest와 참조 이미지·페르소나 MD만 사용자 캐릭터 폴더로 복사합니다. 원본 폴더는 수정하지 않습니다.
- 설정의 팩 관리에서 사용자 팩을 `제거 · 보관`합니다. 원본 폴더는 보관하고 선택 팩은 기본 팩으로 돌아갑니다. 사용자 MD·이름·대화·모델은 삭제하지 않습니다. 보관 목록에서 다시 미리보고 복원할 수 있습니다.

전체 예시: `characters/onggi-clip/manifest.json`, `characters/onggi-sprout/manifest.json`.

바탕화면에서는 `size`의 가로·세로를 기본 50%, 설정에 따라 35/50/65%로 표시합니다. 대화창의 캐릭터 미리보기는 별도 레이아웃 크기를 사용합니다.

## 선택적인 페르소나

manifest의 `personas`에 `base` MD 경로와 `modes` 배열을 지정합니다. `base` ID는 예약되어 있으며 모드는 1~8개, ID는 팩 ID와 같은 영문/숫자/하이픈 규칙이고 중복할 수 없습니다. 각 모드는 `id`, `name`, `file`, 선택적인 `description`을 갖습니다. 기본 예시는 제공하는 4개 팩의 manifest에 있습니다.

MD는 팩 안의 상대 경로, 비어 있지 않은 UTF-8, 파일당 최대 16KiB이며 NUL·외부 경로·팩 밖으로 향하는 링크를 거절합니다. 활성 사용자 MD의 심볼릭 링크는 거절합니다. 사용자 데이터의 `personas/<캐릭터 ID>/`에 활성 편집 파일을 만들고 기존 편집은 덮어쓰지 않습니다. 설정의 MD 폴더가 실제 활성 파일 위치입니다. 기본 성격과 선택한 모드의 내용은 질문별로 고정하고, 다음 질문에 수정 내용을 적용합니다. 실행 코드나 권한 부여 수단이 아닙니다.

`bubbleAnchor`는 build25부터 별도 안내 창의 기준점을 조정합니다. 화면 가장자리에서 안내는 화면 안으로 보정하고 위쪽 공간이 부족하면 캐릭터 아래로 배치하므로, 실제 창 좌표가 항상 지정 점에 그대로 놓이는 것은 아닙니다. 안내 표시/숨김은 캐릭터 창의 크기를 바꾸지 않습니다.


## build26 검증과 미리보기

manifest는 UTF-8 JSON 객체·일반 파일·64KiB 이하이며 이미지와 MD 경로를 팩 내부 canonical 상대 경로로 정규화한다. 내보내기 경로는 `/` 구분자로 저장하여 OS 사이의 폴더 교환을 고려한다. 후보는 읽은 바이트와 SHA-256 revision으로 고정하고, 원본이 미리보기 이후 변경되어도 검증한 snapshot을 설치한다. 후보 token은 10분 후 만료한다.

PNG/WebP는 실제 signature/chunk·치수·프레임 수, SVG는 실행/외부 참조·자동 animate/set를 먼저 검사한다. 래스터는 최대 2048×2048, 최대 32개의 컨테이너 프레임이며 팩 전체의 고유 이미지 픽셀×프레임 합은 8,388,608 이하이다. aliases는 같은 자산을 중복 합산하지 않는다. sandbox 검증 창에서 실제 PNG/WebP bitmap와 SVG DOM 구문·image decode를 확인하고 SVG의 실제 치수도 전체 예산에 포함한다. 10초 초과/검증 화면 종료/손상 decode는 후보를 거절하며 검증 창은 정리한다. 헤더 검사를 전체 decode로 설명하지 않는다.

APNG/animated WebP는 첫 대표 프레임을 최대 512px 정적 PNG로 표시한다. 임의 자동 재생이 정숙/잠금 정책을 우회하지 않도록 하기 위한 처리이며, 컨테이너 전체 애니메이션을 실제 재생해 검증했다는 의미는 아니다. 원본 데이터는 팩에 보존한다. SVG의 execute/외부 필터·그라디언트 참조 제한은 v2에서도 같다.

목록은 metadata와 작은 idle 썸네일만 전송하고 선택한 팩의 이미지/프레임은 revision이 바뀔 때 전달한다. 미리보기는 대기/오류 두 모습과 이름·버전·제작자·출처·이용 조건을 표시하며 실제 모델 응답을 만들지 않는다. 표시 실패는 idle, idle도 실패하면 본체의 작은 기본 표시로 대체하고 실패 URL을 상태 갱신 때 반복 재시도하지 않는다.

## v2 눈 깜빡임

기존 v1 두 팩을 유지하고 `onggi-clip-blink`를 별도 제공한다. v2는 atlas/crop 대신 **전체 공통 캔버스 이미지**만 지원한다. 모든 frame rect는 암묵적으로 `(0,0,canvas.width,canvas.height)`이며 프레임마다 crop/창 resize를 하지 않는다. `animation`의 허용 필드만 읽는다.

```json
"schemaVersion": 2,
"animation": {
  "canvas": { "width": 180, "height": 250 },
  "pivot": { "x": 0.5, "y": 1 },
  "rendering": "smooth",
  "blink": {
    "loop": true,
    "frames": [
      { "file": "idle.svg", "durationMs": 4000 },
      { "file": "sleeping.svg", "durationMs": 120 },
      { "file": "idle.svg", "durationMs": 120 }
    ]
  }
}
```

위는 manifest에 추가하는 필드 예시이다. 프레임은 2~32개, 시간은 정수 42~10000ms(최대 약 24fps), 한 동작은 60초 이하이다. canvas는 1~2048 정수, pivot은 0~1의 공통 CSS 변형 기준점, rendering은 smooth/pixel이다. decode 치수가 canvas와 다른 프레임은 거절한다. SVG는 명시적 width/height를 넣어 브라우저의 기본 intrinsic 크기에 의존하지 않는다.

생동감 프로필의 idle 상태에서만 blink를 실행한다. 프레임은 renderer 안에서 사전 decode한 이미지로 교체하며 매 프레임 IPC·저장·모델 호출은 없다. 숨김/잠금/절전/드래그/reduced-motion/배터리 절약/캐릭터 변경에서는 멈춘다. 승인·작업·답변·쉬기는 v1 상태 이미지로 돌아간다. loop=false는 한 번 실행 후 idle로 돌아가며 해당 revision의 자동 재시작은 하지 않는다. OS reduced-motion이 우선한다.

## 사용자 말투와 팩 복구 파일

사용자 말투는 `personas/<characterId>/modes.json`과 앱 생성 `user-UUID.md`로 저장한다. 기본 base/제공 모드는 이름 변경·보관하지 않고 복제본을 만든다. 사용 가능 모드는 캐릭터당 최대 8개(base 제외), 보관 포함 사용자 등록은 32개이다. 이름은 파일 경로로 사용하지 않는다. 보관 MD는 그대로 남기며 활성 선택 모드는 다른 모드를 고른 후 보관한다. 기본 복원은 선택한 MD를 UUID 백업한 뒤 템플릿으로 교체한다.

`mode-create.json`은 생성 중 종료된 registry/MD를 재시작에 함께 복구한다. 외부에서 바뀐 목록/복구 MD는 보존하고 오류를 안내한다. 편집 초안은 현재 앱의 메모리이며 MD 저장 성공 전까지 파일에 적용되지 않는다. 파일 다시 읽기도 초안을 자동 삭제하지 않는다. 기본 내용 복원은 선택한 초안도 초기화한다.

팩 변경은 같은 데이터 폴더의 `.stage-UUID` → 기존 `.archive-UUID` 보관 → 활성 폴더 → 설정 저장 → `pack-change.json` 완료 순서다. 여러 폴더/파일 전체의 완전한 원자 교체·전원 상실 fsync 내구성을 보장하지 않는다. 미완료 변경은 해시/소유 범위를 확인해 이전 팩과 선택 설정으로 복구하며, 추가/변조 파일은 삭제하지 않고 쓰기 차단·수정 안내로 남긴다. 폴더 내보내기는 manifest·참조 이미지·제공 MD만 기본 포함하고 편집 MD/활성 사용자 말투 포함은 명시적 선택이다. 대화·상태 파일·인증 데이터는 넣지 않는다. ZIP이나 실행 확장팩은 지원하지 않는다.

## alpha.12 개인화 왕복과 복구

말투 이름은 trim→NFC 정규화 후 Unicode 코드 포인트 1~60개이며 제어 문자를 허용하지 않습니다. 화면상 문자 묶음 수와 같다는 뜻은 아닙니다. 사용자 registry와 같은 user-UUID가 편집 포함 팩에 있으면 기존 사용자 이름·MD·보관 상태·소유권이 우선하며 중복 집계하지 않습니다. 사용자 MD가 없으면 템플릿으로 조용히 채우지 않고 오류를 표시합니다. 새 프로필에서는 내보낸 모드가 제공 모드로 로드됩니다.

내보내기도 원본을 다시 읽고 동일한 SVG/decode 검증을 거친 후 참조 데이터만 씁니다. 설치는 pack-preview로 후보를 검사한 뒤 pack-apply 트랜잭션으로 확정합니다. 0팩 복구 표시는 실제 팩이 아니며 질문·선택·내보내기를 막습니다. 같은 ID의 정상 팩을 재설치하면 임시 표시를 제거합니다. 마지막 정상 팩은 다른 정상 팩을 먼저 설치한 뒤 제거합니다.
