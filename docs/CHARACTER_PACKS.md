# 캐릭터 팩 v1

캐릭터 팩은 이미지와 JSON만 포함합니다. 본체의 대화, 권한, Codex 연결을 수정하지 않습니다.

## 최소 구성

```text
my-character/
  manifest.json
  idle.svg
```

```json
{
  "schemaVersion": 1,
  "id": "my-character",
  "name": "내 친구",
  "description": "작고 포근한 친구",
  "version": "1.0.0",
  "size": { "width": 150, "height": 190 },
  "bubbleAnchor": { "x": 0.65, "y": 0.12 },
  "motion": "sway",
  "states": { "idle": "idle.svg" }
}
```

`id`는 영문 소문자로 시작하는 소문자·숫자·하이픈, 최대 48자입니다. 같은 ID를 중복 설치할 수 없습니다. 이름은 1~60자입니다. 크기는 논리 픽셀로 가로/세로 각각 60~220입니다. 앵커는 캐릭터 좌상단 기준 0~1이며 말풍선 위치와 꼬리를 보정합니다.

`motion`: `sway`(좌우 흔들림), `float`(위아래 움직임), `bounce`(작은 도약). 기본값은 `sway`입니다. 생각 중·알림·답변·쉬기 상태는 공통 상태 애니메이션이 우선합니다. 움직임 줄이기 설정은 모든 캐릭터에 적용합니다.

## 상태

| 키 | 의미 |
|---|---|
| idle | 대기 |
| listening | 질문 입력 |
| thinking | 실행 중 |
| replying | 응답 도착 직후 |
| attention | 승인·추가 답변 필요 |
| error | 작업 실패 |
| sleeping | 사용자가 쉬기 선택 |

`idle`은 필수입니다. 나머지 파일이 지정되지 않으면 `idle`로 대체합니다. 지정된 파일이 실제로 없으면 팩 설치를 거절합니다.

## 이미지와 설치

- SVG, PNG, WebP를 지원합니다. 이미지 하나는 최대 3MB, 팩의 참조 이미지 합계는 최대 24MB입니다.
- 경로는 팩 내부 상대 경로입니다. 외부 경로와 외부를 가리키는 심볼릭 링크를 거절합니다.
- SVG의 스크립트·이벤트 핸들러·외부 참조·DOCTYPE·ENTITY·`url(...)`은 거절합니다. v1에서 그라디언트/필터 참조도 지원하지 않습니다. 단순 도형과 선을 사용하거나 PNG/WebP로 내보냅니다.
- JS, CSS, HTML, 모델 코드, 셸 스크립트는 팩 실행 자산으로 사용하지 않습니다.
- 설치 시 manifest와 참조 이미지들만 사용자 캐릭터 폴더로 복사합니다. 원본 폴더는 수정하지 않습니다.
- 추가 팩 삭제는 앱을 종료한 뒤 설정에서 연 사용자 캐릭터 폴더의 해당 디렉터리를 삭제합니다. 선택 팩이 없으면 다음 시작 때 기본 팩으로 돌아갑니다.

전체 예시: `characters/onggi-clip/manifest.json`, `characters/onggi-sprout/manifest.json`.

바탕화면에서는 `size`의 가로·세로를 각각 50%로 표시합니다. 대화창의 캐릭터 미리보기는 별도 레이아웃 크기를 사용합니다.
