# 이전 대화 삭제 — alpha.8

2026-10-06. `이전 대화`의 각 항목 오른쪽에 `삭제` 버튼을 추가했습니다. 삭제 창에서 대화 제목과 범위를 확인한 뒤 `영구 삭제`를 눌러 실행합니다. 기본 포커스는 `취소`이며 Esc로 취소할 수 있습니다. 삭제 처리 중에는 버튼과 Esc 취소를 막아 완료 여부를 명확하게 표시합니다.

## 삭제 범위

옹기봇에 등록된 대화 ID만 처리합니다. 로컬 목록 인덱스와 `conversations/<ID>.json`, 해당 대화의 `.tmp`를 제거합니다. 현재 대화를 삭제하면 현재 메시지·thread 연결·입력 초안 캐시도 정리해 새 대화 상태로 돌아갑니다. 다른 대화와 모델/추론/속도 설정은 유지합니다.

CLI 세션 ID가 있으면 저장된 CLI 연결의 `thread/delete`를 사용합니다. 정상 삭제는 CLI의 실제 rollout 파일과 관련 메타데이터를 제거하며 파생된 하위 세션도 함께 처리합니다. 삭제 알림에서 확인된 다른 옹기봇 소유 ID가 있으면 그 로컬 기록도 정리합니다. 연결된 CLI 세션이 없는 체험/로컬 대화는 로컬 기록만 제거합니다. [공식 OpenAI App Server 문서](https://learn.chatgpt.com/docs/app-server)

앱에서 되돌리기를 제공하지 않습니다. 기존 이관/손상 복구용 `state.json.backup-*` 등의 백업과 외부 백업은 별도로 유지하며 이번 삭제 대상에 포함하지 않습니다. 삭제 창에도 이 범위를 표시합니다. 디스크의 보안 삭제나 모든 외부 사본 제거를 보장하는 기능은 아닙니다.

실행/대기/접수/기록 조회 중에는 삭제할 수 없습니다. 외부 Codex 세션 ID를 입력해 임의 삭제할 수 없고, 삭제 확인이 없는 IPC 요청도 거절합니다. 같은 세션이 다른 CLI에서 실행 중이면 CLI가 삭제를 거절할 수 있으며 앱에 해당 오류를 표시합니다.

## 순서와 실패 처리

1. 현재 기록을 저장하고 `delete-journal.json`에 대상 소유 ID와 CLI 연결 정보를 기록합니다. 본문 복사본은 넣지 않습니다.
2. CLI 세션이 있으면 먼저 실제 세션 삭제를 요청합니다. 다른 CLI/작업 폴더에 연결된 대화는 별도 프로세스를 사용해 현재 대화 연결을 유지합니다.
3. CLI 성공 후 저널을 `cli-deleted`로 확정하고 목록 인덱스에서 대상 ID를 제거합니다.
4. 해당 JSON과 임시 파일을 제거하고 삭제 저널을 지웁니다.

CLI 오류/연결 중단/확인되지 않은 응답에서는 로컬 기록을 유지합니다. 해당 항목에 `삭제 확인 필요`와 `재시도`를 표시하며, 삭제 확인이 필요한 대화의 재개/새 질문은 막습니다. 다른 대화와 새 대화는 사용할 수 있습니다. 여러 삭제를 동시에 진행하지 않습니다.

CLI 삭제 후 로컬 파일 정리가 실패하면 부분 완료를 알리고 저널을 보존합니다. 같은 확인 창에서 다시 시도하거나 앱을 재시작하면 확인된 로컬 정리를 마무리합니다. CLI 확인 전의 pending 삭제는 재시작해도 자동으로 원격 삭제하지 않으며 사용자가 다시 확인합니다. 확인값/소유/경로가 맞지 않으면 파일을 지우지 않습니다.

설치 CLI 0.160.0은 이미 없어진 세션의 반복 삭제에 `-32600`, `no rollout found for thread id <ID>`를 반환했습니다. 이 정확한 오류와 동일 ID의 재조회 부재를 함께 확인한 경우에만 로컬 정리를 계속합니다. 인증/네트워크/미지원 메서드 오류를 이미 삭제된 세션으로 취급하지 않습니다. 향후 CLI에서 오류 방식이 달라지면 보존 후 오류 표시가 우선입니다.

삭제 완료 알림은 RPC 응답 뒤 도착할 수 있습니다. 앱은 알림 하나의 즉시 도착에만 의존하지 않으며 요청 성공을 기준으로 대상 루트를 처리합니다.

## 검증

- 핵심 테스트 28개: 기존 23개 + 소유 대화/임시 파일 삭제와 다른 대화 보존, pending 재시작 보존, 확인된 정리 실패 복구, 외부 소유·경로 이탈 거절, 미완료 저장 저널과 삭제 충돌 방지 5개.
- `npm run smoke:delete`: 별도 앱 프로필과 지속 저장 테스트 CLI로 확인 창/취소 기본값/취소, 활성 대화 초기화, 실제 테스트 CLI 세션 삭제, 진행 중 거절, 외부 ID·미확인 요청 거절, CLI 실패 후 로컬 보존·재시도, 이미 제거된 CLI 세션, 다른 대화 보존과 재시작을 검증합니다.
- `npm run codex:delete-smoke`: 검증용으로 새로 만든 실제 CLI 세션에 짧은 Luna/high 답변을 한 번 저장한 후 그 ID만 삭제합니다. 삭제 전 rollout 존재, 삭제 후 파일 제거와 재조회 거절, 삭제 알림과 반복 삭제 오류를 확인합니다. 계정 이용량을 사용합니다.

근거는 `artifacts/deletion-ui-smoke.json`, `artifacts/alpha-delete-history.png`, `artifacts/real-delete-smoke.json`입니다. 사용자의 기존 대화는 테스트에서 삭제하지 않았습니다. 모델·기록·시간 측정·긴 기록·Markdown/캐릭터 UI도 회귀 검증합니다.
