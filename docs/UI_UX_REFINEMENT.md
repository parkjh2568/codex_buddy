# 대화 UI·접근성

현재 alpha22/build38의 대화·설정 동작을 정리한다. 말투 옆 `+`, 답변 중심 심플 모드, 보호 유예를 포함한 30초 전체 숨김, 상세 모서리 드래그와 설정 정렬을 지원한다. 설계와 도입 당시 검증은 [UI 작업계획](history/CHAT_UI_REDESIGN_PLAN_2026-10-13.md)·[alpha21 구현 결과](history/REMAINING_IMPLEMENTATION_RESULT_2026-10-14.md)에, 최신 검증·패키지·실제 화면 확인 범위는 [Mac 후속 결과](MAC_FOLLOWUP_RESULT_2026-10-15.md)에 기록한다.

일반 대화는 공통 좌우 여백/기준선, 심플은 16px 여백을 사용한다. 입력창 하단의 말투 옆 `+`에 이미지·파일·클립보드 이미지·작업 목적·스킬을 모았다. 첨부 미리보기와 기본값이 아닌 목적/선택 스킬 요약은 입력창에 남긴다. 말투·`+`·모델/추론·중단·전송의 폭을 나누고 긴 이름은 생략해 버튼 공간을 보존한다. 넓은 상세 창에서는 최대 읽기 폭을 제한한다.

`+`와 모델 팝업은 동시에 열지 않고 밖 클릭/Esc로 닫는다. Escape는 열린 모달, 팝업, 창 숨김 순서를 지킨다. 파일 선택 전에 첨부 팝업을 닫고 기존 trusted 붙여넣기·드롭 경계를 유지한다. 모델 변경은 다음 질문부터 적용한다.

입력창은 여러 줄에 맞춰 높이가 늘고 줄이면 복귀한다. Enter 전송·Shift+Enter 줄바꿈·한글 조합 중 전송 억제를 유지한다. 작업 중 보내기는 일반/심플에서 FIFO에 접수한다. 새 대화의 첫 접수 때 텍스트/첨부 초안은 같은 대화 ID로 이전한다. 접수 실패는 초안을 유지한다.

## 심플 말풍선과 상세 창

최초 심플 모드는 작은 입력 말풍선이며, 답변이 있으면 main이 선택한 assistant 답변 하나와 아래 입력창을 표시한다. 현재 실행 답변을 우선하고, 대기 질문이나 내용 없는 대기 취소 카드가 이전 전달 답변을 밀어내지 않게 한다. 사용자 질문 카드·전체 도구 로그·복사/측정 도구는 상세에서 확인하며, 체험/실제 연결과 실패 안내는 유지한다. 이미지뿐인 답변은 빈 텍스트 상자 없이 표시한다.

심플 높이는 헤더·입력·선택 답변의 자연 높이에 맞추고 설정의 기본 410px/넉넉하게 480px 및 화면 작업 영역으로 제한한다. 긴 답변과 첨부 목록은 내부에서 스크롤하며 입력창이 밀려나지 않게 한다.

저장 성공·응답 이미지 처리 완료·실제로 보이는 미리보기의 준비 또는 실패 안내를 확인한 뒤 30초를 계산한다. 수신 대답속도 측정을 꺼도 표시 수명은 별도로 작동한다. 30초가 지나면 **입력창을 포함한 말풍선 전체를 숨기고 버디 클릭으로 다시 연다**. 일반 상태 갱신으로 시간을 다시 시작하지 않는다.

**확정한 보호 정책:** 초안·첨부 선택·승인 처리 중 자동 숨김을 미루고, 처리가 끝나면 새로 30초를 제공한다. 한글 조합·열린 팝업·실행/대기·큐 편집·저장/복구 상태도 보호한다. `×`는 보호 상태와 관계없이 즉시 숨기며 대화·초안·첨부·작업을 취소하지 않는다. 대화/답변 전환·다시 열기·상세/탭 전환·화면 복구·잠금/절전에서는 이전 표시 세대와 예약을 무효화한다.

상세 창은 네 모서리 드래그로 조절한다. 포커스한 모서리에서 방향키는 8px, Shift+방향키는 32px을 적용한다. 유효한 panel/main frame·세션·화면 영역을 검증하며 창 밖으로 이동한 포인터와 빠른 release도 정리한다. 크기 조절 중 파일을 반복 저장하지 않는다. 상세 크기·위치는 런타임에서 보존하므로 확장·설정/기록·재열기에서 유지되며 앱 재시작까지 저장하지는 않는다. 심플 배치가 상세 bounds를 덮어쓰지 않는다.

## 기록·이미지·설정

상세 기록은 최근 100개/약 256KiB 텍스트부터 표시하고 이전 묶음을 추가한다. 심플은 선택한 답변 하나만 만든다. 숨겨진 패널은 메시지/상태 캐시만 갱신하고 보일 때 DOM을 반영한다. 상세에서 지난 내용을 읽으면 스크롤을 보존하고 `맨 아래로`를 제공한다.

답변은 정제된 Markdown으로 표시하며 원문/코드 복사 범위를 유지한다. 응답/첨부 이미지는 작은 보관 미리보기를 필요한 위치에서 로드하고 원본 열기 때 소유 참조를 검사한다. 실패 안내와 텍스트는 유지한다. 이미지 생성 원본을 새로 만들지 않고 기존 CLI 결과를 다시 읽을 수 있다.

친구 이름은 NFC 정규화 후 1–20 코드 포인트·제어 문자 거절 규칙을 사용한다. 저장 실패는 메모리 이름도 되돌린다. 이름은 질문 원문·기존 대화·앱 데이터 폴더를 바꾸지 않으며, 변경 후 접수한 질문의 말투 지시에 반영한다. 선택 탭의 aria-current, 설정 aria-pressed, 키보드 포커스·동작 줄이기를 유지한다.

설정의 select·시간 입력·스위치와 이름/저장 줄의 기준선을 맞추고, 팩·말투·연결·사용량의 접기 헤더를 통일했다. 캐릭터 이미지는 같은 박스 안에서 비율을 유지하고, 긴 이름·경로·도움말·복구 목록은 동작 버튼을 덮지 않게 줄바꿈/스크롤한다.

## 검증 범위

alpha21 도입 당시 390×580·460×740·720×900 각각 3스킨의 정렬/overflow와 색상 전환 후 캡처를 확인했다. 이후 alpha22의 단위·Electron·패키지 검사와 실제 선택기·네 모서리·OS 클립보드 API 검증은 [Mac 후속 결과](MAC_FOLLOWUP_RESULT_2026-10-15.md)를 따른다. 당시 결과를 문서 정리에서 재실행한 검사로 표시하지 않는다.

`npm run smoke`에는 일반 460×740/작은 390×580 레이아웃·입력 확장·긴 이름·Markdown·큐·notice 검사가 포함된다. `smoke:buddy`는 세 스킨의 심플 레이아웃, `smoke:attachments`는 첨부/심플 FIFO, `smoke:stability`는 숨김/재표시·renderer 복구를 확인한다. `smoke:chat-ui`는 격리 체험 환경에서 `+`·답변 선택·실제 30초 대기·보호·미리보기와 크기 조절 소유권을 검사한다. 프로그래밍 기하/Chromium 입력 검사는 macOS의 실제 모서리 드래그 검증과 구분한다.

build16–25의 변경 경위·네이티브 화면·좌표/프레임 수치·당시 실패와 검증 제한은 [UI 이력](history/UI_UX_REFINEMENT.md)에 보존했다. alpha20/build36의 단위 147개·Electron 14종·패키지 85개 검증은 [당시 결과](history/FINAL_IMPLEMENTATION_RESULT_2026-10-13.md)이며 새 UI의 완료 근거로 바꾸지 않는다. Windows/혼합 DPI·스크린리더·OS 합성 영상·장시간 사용 평가는 별도 미검증이다.
