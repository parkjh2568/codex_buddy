# 대화 UI·접근성

일반 대화는 공통 좌우 여백/기준선, 미니는 16px 여백을 사용한다. 말투·모델/추론·중단·전송 버튼은 입력창 하단 한 줄에 배치하고 긴 이름은 생략해 버튼 공간을 보존한다. 모델 팝업은 밖 클릭/Esc로 닫으며 변경은 다음 질문부터 적용한다.

입력창은 여러 줄에 맞춰 높이가 늘고 줄이면 복귀한다. Enter 전송·Shift+Enter 줄바꿈·한글 조합 중 전송 억제를 유지한다. 작업 중 보내기는 일반/미니에서 FIFO에 접수한다. 새 대화의 첫 접수 때 텍스트/첨부 초안은 같은 대화 ID로 이전한다. 접수 실패는 초안을 유지한다.

## 기록·이미지·설정

긴 기록은 최근 100개/약 256KiB 텍스트부터 표시하고 이전 묶음을 추가한다. 미니는 최신 두 카드만 만든다. 숨겨진 패널은 메시지/상태 캐시만 갱신하고 보일 때 DOM을 반영한다. 지난 내용을 읽으면 스크롤을 보존하고 `맨 아래로`를 제공한다.

답변은 정제된 Markdown으로 표시하며 원문/코드 복사 범위를 유지한다. 응답/첨부 이미지는 작은 보관 미리보기를 필요한 위치에서 로드하고 원본 열기 때 소유 참조를 검사한다. 실패 안내와 텍스트는 유지한다. 이미지 생성 원본을 새로 만들지 않고 기존 CLI 결과를 다시 읽을 수 있다.

친구 이름은 NFC 정규화 후 1–20 코드 포인트·제어 문자 거절 규칙을 사용한다. 저장 실패는 메모리 이름도 되돌린다. 이름은 대화 원문·CLI 입력·앱 데이터 폴더를 바꾸지 않는다. 선택 탭의 aria-current, 설정 aria-pressed, 키보드 포커스·동작 줄이기를 유지한다.

## 검증 범위

`npm run smoke`에는 일반 460×740/작은 390×580 레이아웃·입력 확장·긴 이름·Markdown·큐·notice 검사가 포함된다. `smoke:buddy`는 세 스킨의 미니 레이아웃, `smoke:attachments`는 첨부/미니 FIFO, `smoke:stability`는 숨김/재표시·renderer 복구를 확인한다.

build16–25의 변경 경위·네이티브 화면·좌표/프레임 수치·당시 실패와 검증 제한은 [UI 이력](history/UI_UX_REFINEMENT.md)에 보존했다. Windows/혼합 DPI·스크린리더·OS 합성 영상·장시간 사용 평가는 별도 미검증이다. 최신 결과는 [알파 보고서](ALPHA_REPORT.md)를 따른다.
