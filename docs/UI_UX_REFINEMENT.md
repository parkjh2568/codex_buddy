# 대화 UI와 접근성

대화·설정의 현재 배치·입력·표시 수명 규칙이다. 사용 방법은 [사용자 가이드](USER_GUIDE.md), 실제 확인 범위는 [검증 상태](ALPHA_REPORT.md)를 따른다. 과거 감사·계획·결과는 [UI 이력](history/UI_UX_REFINEMENT_2026-10-20.md)에 보존한다.

## 입력과 팝업

화면 스킨은 paper/night/mono/classic을 제공한다. classic은 기존 10색 팔레트와 본체의 스킨 범위 CSS로 노란 안내/심플 말풍선·회색 상세/설정·입체 컨트롤을 표현한다. 캐릭터·말투·표시 프로필과 독립적이다. 안내 창에도 스킨 ID를 적용하며 테마 변경은 입력 높이·열린 팝업 위치만 재평가하고 대화 DOM·초안·포커스·같은 답변의 숨김 세대를 새로 만들지 않는다. 실제 기하·클릭·화면 수용 상태는 [릴리스 현황](ALPHA_REPORT.md)을 따른다.

paper는 `따뜻한 종이`로 표시하며 종이색 바탕·먹갈색 글자·엄버 강조를 사용한다. 짧은 환영/화면 제목에 시스템 명조를 적용하고 대화 본문·입력·조작에는 시스템 고딕을 사용한다. 장식 구분선과 입력/선택기의 조작 경계를 구분한다. 다른 스킨 팔레트와 클래식의 입체 형태는 유지한다.

대화·이전 대화·설정은 한 탐색 집합을 공유한다. 현대 스킨은 720px 이상 상세 창에서 104px 좌측 탐색을 사용하고, 좁은 창과 클래식은 가로 탐색을 사용한다. 작은 이름/닫기 헤더와 콘텐츠 열을 분리하며 탐색 배치만 바꿀 때 대화/입력 노드를 다시 만들지 않는다. 설정 진입은 같은 탐색의 `설정`, 심플은 헤더의 설정 버튼을 사용한다.

일반 대화는 공통 좌우 여백/기준선을, 심플은 16px 여백을 사용한다. 넓은 상세 창은 최대 읽기 폭을 제한한다. 말투 옆 +에 첨부·작업 목적·스킬을 모으고, 선택 첨부와 기본값이 아닌 목적/스킬 요약은 입력창에 남긴다. 말투·+·모델·중단·전송의 폭을 나누며 긴 이름은 생략해 조작 영역을 보존한다.

현대 상세 입력은 하단선과 포커스로 구분하고 심플 입력은 작은 외곽선과 입력 면을 사용한다. resize/스킨 재배치는 한 프레임에 묶고 최신 입력 높이를 반영한 뒤 열린 메뉴 위치를 계산한다. 숨긴 화면은 측정을 미루고 표시/대화 탭 복귀에서 높이를 재평가한다.

입력은 여러 줄에 맞춰 늘고 줄이면 복귀한다. Enter 전송·Shift+Enter 줄바꿈·한글 조합 중 전송 억제를 지킨다. 복합 요청/큐/첨부/긴 초안 상태에서는 보조 정보를 스크롤하되 전송·중단·입력은 조작 가능해야 한다. 일반/심플은 같은 접수 FIFO와 대화별 초안을 사용한다.

+와 모델 팝업은 동시에 열지 않고 밖 클릭/Esc로 닫는다. Escape는 열린 모달 → 팝업 → 창 숨김 순서다. 파일 선택 전 첨부 팝업을 닫고 trusted 붙여넣기/드롭 경계를 유지한다. 자동 높이/resize는 팝업을 현재 버튼과 viewport에 맞춰 재배치한다.

## 심플 말풍선과 상세 창

최초에는 입력창만 표시한다. 답변이 있으면 현재 실행 assistant 또는 마지막 전달 assistant 하나와 아래 입력창을 표시한다. 빈 대기 취소 카드가 전달 답변을 밀어내지 않으며 이미지뿐인 답변에는 빈 텍스트 상자를 만들지 않는다. 질문 카드·진행 정보·복사/측정 도구는 상세에서 확인하고 실제/체험·실패 안내는 유지한다.

심플은 기본 폭 360px·최대 높이 410px, 넉넉한 설정은 폭 400px·최대 높이 480px이다. 최초 높이는 약 210px에서 내용에 맞춘다. 헤더·입력·답변의 자연 높이와 화면 작업 영역으로 제한하고 긴 답변/첨부는 내부 스크롤한다.

저장 성공·이미지 처리 완료·실제로 보이는 미리보기 준비 또는 실패 안내 뒤 30초를 계산한다. 시간 측정 옵션과 독립적이며 일반 상태 갱신으로 다시 시작하지 않는다. 만료하면 입력창을 포함한 전체를 숨기고 버디 클릭으로 다시 연다.

초안·IME·첨부 선택·열린 팝업·승인·실행/대기·큐 편집·저장/복구·중요 오류 동안 숨김을 미룬다. 보호가 끝나면 새 30초를 준다. X는 즉시 숨기며 대화/초안/첨부/작업을 취소하지 않는다. 대화/답변 전환·재열기·상세/탭 전환·renderer 복구·잠금/절전은 옛 표시 세대와 예약을 무효화한다.

상세 창은 초기 460×740, 최소 390×580이지만 작은 작업 영역에서는 더 줄인다. 네 모서리 드래그와 포커스한 모서리의 방향키 8px·Shift+방향키 32px을 지원한다. main/frame·세션 token·현재 화면 영역을 검증하고 RAF/한 번의 진행 요청으로 묶는다. 창 밖 포인터도 문서 pointer ID로 종료한다. 시작 IPC보다 먼저 release되면 마지막 좌표를 같은 token에 적용하고, cancel/lost는 추가 변경 없이 종료한다.

상세 bounds는 같은 실행 동안 확장·설정/기록·재열기에 유지한다. 심플 배치가 덮어쓰지 않으며 앱 재시작까지 영속 저장하지 않는다. resize 중 파일을 반복 저장하지 않는다.

## 버디 창

기본 캐릭터 창은 120×143, 별도 안내는 196×52 논리 픽셀이다. 캐릭터는 기본 50%와 35/65% 배율을 사용하며 팩 크기 변경은 [팩 규격](CHARACTER_PACKS.md)을 따른다. 안내 유무가 캐릭터 크기/앵커를 바꾸지 않는다. 안내는 화면 경계 안에 두고 위 여유가 없으면 아래로 표시한다.

드래그는 시작점의 절대 좌표와 포인터 캡처를 사용한다. Dock/작업 표시줄·화면 밖으로 이동할 수 있으며 재시작/화면 구성 변경은 보이지 않는 위치만 복구한다. 옛 250×270 위치도 캐릭터 기준점으로 변환한다. 트레이에서 위치 초기화와 화면 복구를 제공한다. macOS는 비활성 panel·전용 창 옵션을 사용하며 Windows 동등 동작은 별도 수용이다.

대기 안내는 3초 뒤 숨고 hover 동안 유지한다. 하단 메뉴는 hover 진입 후 3초 뒤 숨는다. 드래그 중 안내/메뉴/장식을 숨긴다. 투명 여백과 숨긴 메뉴는 클릭을 통과시키고 notice는 좁은 대화 열기·영역 갱신만 허용한다.

## 기록과 설정

숨겨진 패널은 캐시만 갱신하고 표시 때 DOM을 반영한다. 상세에서 지난 기록을 읽을 때 스크롤을 유지하고 맨 아래로를 제공한다. 단계 표시·검색/목록 예산은 [대화 조회](CONVERSATIONS.md)에 둔다. 목록 열기/즐겨찾기는 바로 표시하고 제목/내보내기/삭제는 이름 있는 더 보기 팝업으로 모은다.

추가 질문은 request/question ID별 입력 노드를 유지해 재정렬에서 입력·선택·포커스를 보존한다. 질문 의미가 바뀌면 이전 초안을 별도로 남긴다. 대화/설정의 긴 이름·경로·경고·보관 목록은 버튼을 덮지 않게 줄바꿈/스크롤한다. 카드 이미지는 같은 박스에서 비율을 유지하고 카드·select·시간·스위치·저장 줄의 기준선을 맞춘다.

친구 이름은 trim/NFC 뒤 1–20 코드 포인트이며 제어 문자를 거절한다. 저장 실패는 메모리 이름도 되돌린다. 기존 질문/기록/데이터 폴더는 바꾸지 않고 이후 접수 말투에 반영한다. 대화 글자 배율은 본문/Markdown/입력에만 적용하며 설정/작업 정보 크기는 유지한다.

설정은 이름·텍스트 섹션 바로가기·대화/화면을 먼저 두고 캐릭터 목록과 크기는 친구 모습으로 접는다. 표시 프로필은 움직임에, 시간 측정은 대화/화면에 둔다. 이름은 다른 폼과 같은 기준선을 사용하고 기록은 목록 행과 선택 면으로 표현한다. 위험 동작은 스킨별 대비를 유지하며 모달 오류는 해당 모달 안에 표시한다. 탭 aria-current·설정 aria-pressed·키보드 포커스와 OS reduced-motion을 유지한다. 정숙/일상/생동감이 실제 진행·승인·저장 오류를 숨기지 않는다.

MD 충돌·복원은 파일과 초안을 모두 보존한다. 비교 후 다시 바뀌면 재확인하며 요청 처리 중 새 입력을 지우지 않는다. 세부 파일/registry 규칙은 [팩과 말투](CHARACTER_PACKS.md#사용자-말투와-팩-복구-파일)에 둔다.

## Markdown 표시

제목·강조·취소선·목록·인용·구분선·인라인 코드·코드 블록·표·HTTP/HTTPS 링크를 지원한다. 질문/오류/승인은 일반 텍스트이며 답변 원문은 보관/복사에 그대로 사용한다. 표와 긴 코드는 가로 스크롤하고 코드 복사는 해당 블록만 복사한다.

markdown-it의 HTML 비활성 파싱과 DOMPurify 허용 목록을 적용하고 CJK 플러그인으로 한국어 강조 경계를 처리한다. 외부 이미지 자동 로딩·임의 HTML·JavaScript/file/data URL·코드 구문 강조·수식·실제 체크박스는 허용/지원하지 않는다. 웹 링크는 클릭할 때 시스템 브라우저로 연다. 변경된 답변만 다시 파싱하고 미완성 코드는 완료 때 재해석한다. 생성/첨부 이미지는 소유 참조와 작은 미리보기를 별도 경계로 읽으며 실패 안내와 텍스트를 유지한다.
